# 슬랙 미답변 인박스

슬랙에서 나에게 온 멘션 중 아직 답장하거나 반응하지 않은 것만 추려 `tracker/slack_inbox.md`에 정리합니다.

## 입력

조회 기간(선택, 기본 7일): $ARGUMENTS

## 작업 지시

1. **슬랙 MCP 툴 로드**
   - `ToolSearch`로 슬랙 관련 툴(메시지 검색, 대화 히스토리/스레드 답글 조회, 반응 조회) 스키마 로드
   - 툴이 안 보이면 MCP 서버가 이번 세션에 아직 반영 안 된 것 — 세션 재시작 안내 후 중단

2. **조회는 fork로 격리**
   - `Agent` 툴(`subagent_type: fork`)로 슬랙 조회를 수행해 원본 메시지 덤프가 본 대화 컨텍스트에 쌓이지 않게 한다
   - fork 지시: "최근 N일간 나에게 온 멘션을 검색해서, 각 멘션이 속한 스레드에 내 계정 답글이 있는지 또는 내가 이모지 반응을 남겼는지 확인해라. 둘 다 없는 것만 골라 [보낸사람, 메시지 요약 1줄, 채널, permalink, 타임스탬프]로 압축해서 반환해라. 원본 JSON은 반환하지 마라."

3. **기존 인박스 파일과 병합**
   - `tracker/slack_inbox.md` 읽기 (없으면 새로 생성)
   - permalink 기준 중복 제거 — 이미 파일에 있는 항목(체크 여부 무관)은 건드리지 않는다
   - 새 항목만 "미답변" 섹션에 추가

4. **결과 출력**
   - 새로 추가된 항목 수 + 전체 미답변 개수
   - 새 항목 목록 미리보기

## 파일 형식 (`tracker/slack_inbox.md`)

```markdown
# 슬랙 미답변 인박스

마지막 갱신: YYYY-MM-DD

## 미답변
- [ ] **보낸사람**: 메시지 요약 — [바로가기](permalink) (YYYY-MM-DD, #채널)

## 처리됨
- [x] **보낸사람**: 메시지 요약 — [바로가기](permalink) (YYYY-MM-DD, #채널)
```

## 처리 규칙

- 사용자가 파일에서 `- [ ]`를 `- [x]`로 바꾼 항목은 다음 실행에서도 그대로 유지한다. 다시 미답변으로 되돌리지 않는다
- 슬랙에서 이미 답장하거나 반응한 항목은 애초에 "미답변" 목록에 올리지 않는다
- 슬랙 밖(구두 대화 등)에서 처리된 건은 자동 감지가 안 된다 — 사용자가 파일에서 직접 체크한다

## 주의사항

- 슬랙 조회 결과는 반드시 fork를 거쳐 압축된 형태로 가져온다. 원본 덤프를 본 대화에 그대로 붙여넣지 않는다
- 검색 쿼리는 항상 기간으로 좁힌다. 전체 히스토리 스캔은 하지 않는다
- 모든 출력은 한국어로 작성한다
