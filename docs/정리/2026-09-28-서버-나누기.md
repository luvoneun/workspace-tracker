- 인증·호스트·출처 검사는 `handleRequest` 밖 `safeHandle`(약 3298-3317)에 있다 — 건드리지 않는다.
- `mutations.run`은 재진입 안전(mutation-store.js depth 카운터).
- **함정 1 — 차단 목록 이중 관리**: `CLIENT_BLOCKED`(server.js 약 2227)와 `server.test.js` 약 67-70의 하드코딩 목록이 따로 있고 이미 항목이 다르다.

- `server.test.js`의 절반 가까이는 `automation/` 셸 스크립트 테스트다.

## 할 일 (이 순서로, 단계마다 전체 테스트)
1. **차단 목록을 하나로**: `server.js`가 `CLIENT_BLOCKED`(와 `isClientFile`)를 내보내고, 테스트는 하드코딩 목록 대신 그것을 가져와 "목록의 모든 파일이 실제로 막히는지" + "`tracker/inbox-app`의 서버용 `.js`(화면에서 쓰지 않는 것) 중 목록·패턴에 안 걸린 게 없는지"를 검사한다(새 서버 파일이 목록에서 빠지면 테스트가 실패해야 함 — 거짓 안전 제거). 화면 파일 판별은 `index.html`이 불러오는 스크립트 목록 기준.
2. **테스트 나누기**: 공용 준비(환경 변수·임시 폴더·`require('./server')`·before/after·`post`/`items` 도우미 등, 약 1-148)를 `test-support.js`(이름이 `.test.js`로 끝나지 않게 — 차단 패턴에도 걸리게)로 빼고, 서버 API 테스트를 기능별로: `server.core.test.js`(차단·항목·워크플로·회의) · `server.jira.test.js` · `server.app.test.js`(앱 정보·데이터 버전) · `server.integrations.test.js` · `server.calendar.test.js`(iCal·지금 가져오기) · `server.update.test.js`(업데이트·팀 설치) · `server.channels.test.js`(채널 고르기·백업·자동 등록). **셸 스크립트를 실행해 검사하는 테스트는 전부 `automation.test.js` 하나로**(사용자 결정). 각 파일은 독립 실행 가능해야 한다(`node --test <그 파일>`). 테스트 내용·단언은 **줄이지 않는다** — 옮기기만. 끝나고 전체 개수 641 확인.
3. **테스트 명령 바꾸기**: `node --test *.test.js`(tracker/inbox-app에서)로. 고칠 곳: `AGENTS.md` 14줄, 루트 `README.md` 108줄, 앱 README 496줄, **`release.sh` 48줄**. `design/`의 옛 계획 문서는 과거 기록이라 그대로 둔다.
4. **경로 떼어 내기(얇은 것부터)**: `routes/` 폴더 없이 같은 폴더에 `routes-jira.js` → `routes-integrations.js`(연동·백업·미팅노트·자동화 상태) → `routes-app.js`(about·update·update/status·diagnostics) → `routes-personalize.js`. 각 모듈은 `(req, res, url, ctx) => boolean`(처리했으면 true) 하나를 내보내고, 필요한 것(readBody·JSON 응답 도우미·jiraLive 등·`readScope`를 쓰는 함수)은 **`ctx`로 받는다**(모듈 안에서 server.js를 require하지 않음 — 순환 방지). `readScope`를 쓰는 헬퍼를 옮길 땐 캐시를 인자/ctx로 넘긴다. 새 파일은 **1번의 목록에 등록**하고 테스트가 잡는지 확인. `fetchNow`를 옮기면 5597 테스트의 파일·표식도 같이 고친다(내용은 그대로).
5. **분배기**: `handleRequest`는 공통 가드 → 위 모듈들에 차례로 물어보기 → 남은 경로(항목 추가·수정 24개·보고서·가져오기·꾸미기 외 나머지)는 **그대로 server.js에** → 정적 파일 폴백(맨 끝). `server.js`의 이름·위치·`module.exports`는 유지(옮긴 함수는 재-export).
- **이번에 하지 않는 것**: 항목 추가·수정 경로(24개, `readScope`·`transactional` 최다) — 다음 묶음. 동작·문구·응답 모양 변경, 반복 코드 도우미화(`readBody().then().catch()`), 화면 파일.
