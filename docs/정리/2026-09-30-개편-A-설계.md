# 디자인 개편 A — 조용한 관제판 (설계 확정 문서, 0단계)

## 세 줄
- **왜**: 매일 종일 옆에 띄워 두는 창인데, 오늘 탭 첫 화면(1440×900)에서 오늘 할 일이 7줄 중 1줄만 보인다(첫 줄 위치 806px). 위에 쌓이는 카드와 한 줄에 싣는 뜻(체크박스 꺾쇠·반 채움·상태 여러 개·원문)이 많다.
- **기대 변화**: 첫 화면에서 오늘 할 일을 다 훑고, 줄마다 "지금 가장 급한 한 마디"만 읽는다. 모양·색 토큰은 그대로라 새로 배울 것이 없다.
- **성공 기준**: 같은 가짜 데이터·1440×900에서 오늘 할 일 7줄이 전부 보인다(시안 측정: 첫 줄 219px). 단계마다 옛/새 나란히 비교 페이지에서 의도하지 않은 변화 0, 테스트 전부 통과.

## 1. 방향
- 토큰(색·간격·모서리)·흰 카드 + 연회색 바탕·줄 높이 54px·줄 사이 선 없음은 **그대로**. 바꾸는 것은 **위에 쌓이는 것**과 **한 줄에 싣는 뜻의 수**뿐이다 — "밀도를 목표로 삼지 않는다, 기분이 먼저"(DECISIONS 2026-09-21)와 부딪히지 않는다.
- 파랑은 선택·행동에만, 배지는 급한 말에만, 버튼 세 등급, 누른 줄 옆 상세 카드, 저장 버튼 없음, 삭제는 되돌리기, 데이터 구조·기능·슬랙 복사 형식, 해요체, 기본 HTML·CSS·JS, 밝게·어둡게 — 모두 그대로.

## 2. 공통 규칙 (DESIGN.md에 단계마다 옮길 초안)
1. **주인공 목록이 첫 화면에 다 보인다.** 위에 쌓이는 카드는 개수 버튼이나 한 줄로 접는다.
2. **줄마다 반복되는 말은 그룹 제목으로 올린다**(예: `나중에`, `결정`, `N일째 밀림`).
3. **상태 칸에는 날짜·답변 말 하나만.** 순서: 기한 지남 > 오늘까지 > 답변 왔어요 > 답변 기다리는 중 > 먼 기한. 나머지는 툴팁과 상세 카드 맨 위 `상태 전부` 줄에서 본다.
4. **긴급은 제목 앞 작은 배지 `긴급`**(DESIGN의 급한 배지 그대로). 중요는 줄에 적지 않고 그룹 안 정렬(긴급 → 중요 → 나머지)로만 말한다. — 2026-09-22에 버린 "제목 뒤 글자"는 세 칸 고정이라 흩어져 보였던 것이고, 긴급 하나만 앞에 두면 흩어지지 않는다. 여러 개 선택 C안(1.3.0)이 체크박스 대신 글자로 긴급을 말하는 방식을 이미 검증했다(자리는 오른쪽 상태 칸) — 이번엔 날짜 말과 겨루지 않게 제목 앞으로 옮기고, **선택 모드 안의 긴급 표시도 제목 앞 배지로 맞춘다.**
5. **체크박스는 그 줄을 끝내는 뜻 하나** — 할 일 = 완료, 확인 대기 = 확인됨, 결정 = PRD 반영. **우선순위 꺾쇠는 뺀다. 진행 중 반 채움은 남긴다**(2026-09-29 "며칠째 글자가 거슬린다"로 글자 대신 생긴 자리).
6. **출처 이름이 곧 원문 링크** — `원문` 대신 `슬랙 ↗ · 지라 ↗ · 회의 ↗`, 직접 쓴 것에는 아무것도 붙이지 않는다. 작은 글자 링크의 28px 누르는 자리(`::after`) 규칙을 그대로 옮긴다.
7. **카드 하나에 목록 하나** — 한 화면의 여러 구역은 한 카드 안의 그룹 제목으로 나누고, 빠른 추가는 목록 맨 위.
8. **고치는 자리는 셋** — 값 하나는 그 자리에서, 항목 하나는 옆 카드에서, 여러 항목이나 앱 전체는 팝업에서. 키는 Enter 저장·Esc 닫기.
9. **줄 안의 작은 컨트롤은 글자 버튼·글자 고르개·밑줄 탭을 먼저.** 노란 판 위에 회색 입력칸·회색 버튼을 올리지 않는다. "아직 안 고른 것"은 판 색 대신 주황 선(2px)이나 주황 글자로 표시한다(사용자 취향 — 회의 초안 박스 v2).

## 3. 탭별 변경
### 오늘 (6단계)
- 새로 들어온 것 + 반응 필요 → 머리 버튼 **`들어온 것 N`** 하나. **0개면 버튼만, 새 항목이 있으면 첫 3줄은 펼친 채로 + `N개 더`**(2026-09-21 "맨 위 위치 유지"·"줄의 오늘·나중에·완료 늘 보이기"를 지킨다). 나를 부른 댓글이 맨 위, 출처는 줄 맨 앞. ⌘K의 `오늘 들어온 것` 필터는 오늘 날짜로 거르는 다른 뜻이라 이름 그대로.
- 사용설명서 → 머리의 물음표 버튼. **설치 첫 주에만 카드**로 보이고, 카드 맨 아래 사용 횟수 알림 줄(2026-09-29)은 남긴다.
- 기본 보기 **상태별**: 진행 중 · 어제에서 넘어온 것(가장 오래된 것 N일째 — **진행 중은 섞지 않는다**) · 오늘 할 것 · 끝낸 것. 프로젝트별 보기는 ⋯ 안에 남는다.
- 왼쪽 레일은 요약만: 미팅은 지금·다음만(진행 중 회의는 `진행 중` 글자 — 색만으로 말하지 않기), 확인 대기는 급한 순 한 목록.
  - 캘린더 쪽(personal-9e 확인, 자세히는 `docs/지도/캘린더.md`): 네 갈래(맥 캘린더·Claude·비밀 주소·끔)는 모두 같은 오늘 일정 목록으로 들어오니 화면은 **갈래를 모르고 한 목록만** 쓴다.
  - 상태 다섯 가지를 가른다: ① 끔 ② 첫 읽기 전 → 자리표시(`불러오는 중`) ③ 읽었고 오늘 0개 → 한 줄 `오늘은 미팅이 없어요` ④ 실패 ⑤ 오래됨(마지막 읽기가 오늘이 아님) → ④·⑤는 연동 상태 줄이 안내하고 레일은 조용히. **②와 ③을 같은 빈 모양으로 두지 않는다**("고장인가?"로 읽힘).
  - `지금` = 시작 ≤ 지금 < 끝, `다음` = 오늘 남은 것 중 가장 이른 것. 종일 일정은 지금·다음에서 뺀다. 자정 넘는 일정·펼쳐 온 반복 일정·끝난 미팅도 같은 규칙.
  - 제목은 한 줄 말줄임 + title(긴 글·이모지 가능). 구현 때 캘린더 파일을 건드리면 personal-9e에 먼저 묻는다.
### 프로젝트 (4단계)
- 왼쪽 목록은 0개 프로젝트 숫자를 비운다.
- 지라 띠 카드 한 줄: `지라 · 상태 ▾ · 배포 버전 ▾ · 기한 ▾ · 하위 티켓 7/12 › · 지라에서 열기 ↗`(값 고르개는 지금 부품, 하위 티켓은 0이면 안 적음). 묶음이면 티켓마다 한 줄.
- 구역 카드를 카드 하나로: 오늘 · 나중에 · 확인 대기 · 결정 · 회의 · 아이디어 · 끝낸 것(빈 그룹은 그리지 않음, 빠른 추가 맨 위). `언제 할지` 열을 빼고 오늘/나중에 그룹으로 — 2026-09-21 열 이름 줄을 넣은 이유("줄 앞 오늘/나중에가 무슨 뜻인지")도 그룹 제목이 푼다. 기존 `완료한 업무` 접힘은 `끝낸 것` 그룹으로.
- 결정 그룹 제목에 `· 체크하면 PRD 반영`.
### 회의 (5단계)
- 거르기 칩 셋 → `거르기 ▾` 글자 버튼. 보기 전환(날짜순·프로젝트별)은 **밑줄 탭으로 밖에** 둔다(2026-09-22 "드롭다운 거르기 대신 접는 소제목").
- 회의 줄 오른쪽 한 마디: **`초안 3`은 바탕 없는 `--warn` 주황 글자**(배지가 아닌 상태 글자 — "배지는 급한 말에만"과 부딪히지 않게), 또는 회색 `남은 일 2` · `3시간 뒤`.
- 머리 한 줄: 날짜·시간 · 프로젝트 · 진행 중 · 미팅 노트 ↗ (`미팅 노트 가져옴` 줄 없음).
- 검토할 초안 **v2**: 흰 바탕 + 왼쪽 2px 주황 선("아직 담지 않은 것" — **앱 전체의 "왼쪽 색 세로줄 금지"에 대한 유일한 예외**, 사용자가 시안을 보고 고른 것. 5단계에서 DESIGN.md에 예외 한 줄로 적고, 다른 목록·카드에는 넓히지 않는다. 뜻은 머리 문구 `담기 전까지 저장되지 않아요`가 글자로도 말한다), 종류·언제는 글자 고르개(`할 일 ▾`·`나중에 ▾`), 문구는 평소 글자·누르면 입력칸(초점에서만 파란 테), 머리에 `담기 전까지 저장되지 않아요`. 종류는 소제목(할 일 2 · 결정 1)으로 묶는다. `직접 적어 담기` 큰 판 → 목록 끝 빠른 추가 한 줄. 담기 바는 카드 맨 아래 붙박이: 요약 + `기존 항목 연결`(글자 버튼) + 1차 `N개 담기`. 1.3.0의 `빼기` 글자·✕는 날짜 옆·빼기 되돌리기는 그대로.
### 아이디어·결정 (3단계)
- 결정 머리에 `PRD에 아직 반영하지 않은 것`.
- 결정 줄 한 줄: 정보 줄을 오른쪽 한 칸(`9/29 · 킥오프 ↗`)으로, 결정 문장은 전문 줄바꿈 그대로.
- 아이디어 줄 한 줄: 제목 말줄임 + 오른쪽 `가능성 높음 · 9/30`(가능성은 높음만 — 지금 규칙).
- `반영 완료` 접힘 → 카드 안 맨 아래 그룹.
### 주간요약 (7단계 — 세 칸 그대로)
- `보내기 전 확인` 한 줄: 넣을 구역 칩 · 지라 정보 · `확인 필요 N ›`.
- `확인 필요` 표시(급한 말 규칙 안): **판단은 서버**에서(보고 줄과 근거 업무를 이미 묶어 아는 곳 — 슬랙 복사·확정과 같은 판단), 화면은 표시만, 복사 결과(`reportSlackModel`)에는 넣지 않는다. 기준: 근거 업무가 미완료이거나, **끝낸 업무 문장에 한해** 결과 한 줄이 비었을 때. 앱이 문장을 지어내지 않는다.
- 오른쪽 칸 아래 "재료": 보고에 아직 없는 끝낸 일(+ 넣기)과 고른 문장의 근거 업무. 주차 목록의 '내 일 기록' 자리는 그대로.

## 5. 단계마다 확인
밝게·어둡게 · 1440/1280/1120/900 전부, 640/520/390은 깨짐(가로 스크롤·가림)만(웹 먼저) · reduced-motion · 키보드만 · VoiceOver는 1단계와 마지막에 한 번 · **옛/새 나란히 + 차이 표시 비교 페이지**(1.3.0 배포 때와 같은 방식).

## 6. 이번에 하지 않는 것 (백로그)
- **주간요약 세 칸 → 두 칸**(`‹ 이번 주 ›` 머리·문서/슬랙 모양 세그먼트·재료 칸) — 2026-09-30 v3와 '내 일 기록 → 주차 목록'을 막 확정했고, 슬랙 미리보기를 숨기면 금요일에 붙일 모양을 쓰면서 못 본다. 금요일 몇 번 써 본 뒤 다시.
- **앱 전체 목록 grid 이동**(목록은 Tab 한 번 + ↑↓, Space 완료, Enter 옆 카드) — 줄 위 동작의 키보드 접근, 여러 개 선택의 Space=선택, 주간요약 "문장마다 Tab"(2026-09-30)과 부딪힌다. 할 때는 앱 전체 목록을 한 번에.
