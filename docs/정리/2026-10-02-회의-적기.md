# 회의에서 나온 것 적기 · AI 초안 한 줄 — 구현 명세

- **왜 만드나**: 회의 뒤 할 일을 직접 적어 담는 것이 느리다. 한 건 담을 때마다 칸이 접히고 초점이 사라져 3건에 6번 누른다. AI 초안 카드는 초안 하나에 조절 장치 6~7개가 늘 펼쳐져 초안 5개가 한 화면을 다 쓴다.
- **어떤 사용자 행동이 달라지길 기대하나**: 회의 정리 카드 아래 입력줄에 채팅처럼 막 적고 Enter만 누른다(초점이 안 떠난다). 여러 줄을 붙여 넣으면 줄마다 한 건이 된다. 종류는 적은 뒤에 필요할 때만 바꾼다.
- **무엇을 보면 성공인가**: ① 3건 담기가 6번 누름 → Enter 3번 ② 초안 5개와 담기 버튼, 입력줄이 한 화면에 든다 ③ 직접 적은 뒤 ⌘Z로 되돌릴 수 있다.

시안(확정 2026-10-02, 안 A): `design/회의-적기-시안/index.html`. 떠 있는 채팅 버튼은 만들지 않는다(사용자 철회).

## 정해진 것

- **입력줄은 카드 발에 붙박이**(안 A). placeholder `회의에서 나온 것 적기` 한 줄, 도움말 문장 없음. 평소에는 채움 없는 맨 줄이고 초점에서만 흰 면 + 2px 파란 테. 시트(좁은 폭)에서도 입력줄은 붙박인다.
- **Enter 순간 바로 담긴다**(직접 적은 글은 검토할 것이 없다). 새 줄은 입력줄 바로 위에 시간순으로 쌓이고 초점은 입력줄 그대로. 저장은 뒤에서 차례로(`uiQueueSend`) — 저장 중에 칸을 잠그지 않는다. 실패하면 그 줄에 조용한 표시와 `다시 시도`.
- **여러 줄 붙여 넣기는 줄마다 한 건**. 줄 앞의 `-`·`•`·`1.`은 떼어 낸다. 빈 줄은 버린다.
- **기본 종류는 `할 일`**. 글 맨 앞 `?`는 확인 대기, `!`는 결정(담을 때 떼어 낸다). 줄의 조용한 글자 `할 일 ⌄`을 누르면 작은 목록(할 일 · 확인 대기 · 결정)이 떠서 바꾼다 — 기존 `종류 바꾸기`(retype) 길을 쓴다. 종류를 고르면 초점은 입력줄로 돌아간다.
- **담긴 것은 시간순 한 목록**이고 줄마다 종류 글자가 붙는다(종류 소제목으로 나누지 않는다).
- **AI 초안은 한 줄**: 체크박스 자리에 조용한 `AI` + 문구 + (있으면) 날짜 + `할 일 ⌄`. `빼기`는 손이 닿을 때만(누르는 화면에서는 늘). 문구를 누르면 그 자리에서 문구 칸 + 나중에/오늘 + 기한이 펼쳐진다. `N개 담기`는 `AI 초안` 제목 옆 2차 버튼.
- **기한은 입력줄에서 정하지 않는다** — 담긴 줄의 ⋯에서 정한다.
- **되돌리기**: 직접 적어 담은 것도 ⌘Z로 되돌릴 수 있어야 한다(지금은 기록이 없다 — 이번에 넣는다).
- 모션(전부 transform·opacity, `prefers-reduced-motion`이면 즉시): Enter 새 줄 140ms 넘침 없음 / 종류 목록 등장 220ms scale .88 → 1.025(55%) → 1, 시작점은 누른 글자, 항목 18ms 간격, 닫힘 120ms / 초안 줄 펼침 220ms, 접힘 130ms.
- 서버 변경은 없다(줄마다 `/api/workflow/capture`, 종류 바꾸기는 `retype`).

## 예외 상황

| 상황 | 동작 |
|---|---|
| 한글 조합 중 Enter | 넘긴다(조합이 끝난 Enter만 담는다) |
| 빠르게 연달아 Enter | 줄은 바로 생기고 저장은 순서대로. 두 번째 Enter를 무시하지 않는다 |
| 저장 실패 | 그 줄만 실패 표시 + `다시 시도`, 다른 줄은 그대로. 글은 잃지 않는다 |
| 같은 글 두 번 | 각각 한 건(막지 않는다) |
| `?`·`!`로 시작해야 하는 글 | 목록에서 종류를 바꿔 쓰거나 앞에 빈칸 — 문서에 한 줄 |
| 붙여 넣은 줄이 아주 많음 | 줄마다 한 건이되 한 번에 30줄까지, 넘으면 담지 않고 알린다 |
| 입력 중 자동 갱신 | 입력줄에 초점이 있는 동안 구역 다시 그리기를 미룬다(기존 장치) |
| 종류 목록이 화면 아래에 걸림 | 위로 뒤집는다 |
| 기록 안 된 회의(캘린더 연결 없음)·기존 항목 연결 | 지금 동작 그대로, 자리만 새 순서에 맞춘다 |
| 담은 뒤 결과 카드(`오늘로` 등) | 지금 동작 그대로 |
| 초안이 0개 | 초안 구역 없음, 입력줄과 담긴 목록만 |
| 옛 데이터·옛 초안 파일 | 형식이 안 바뀌므로 해당 없음 |
