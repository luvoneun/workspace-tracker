## 할 일 (좁은 폭 = 520px 이하에서만, 넓은 폭은 그대로)
1. **줄 동작 버튼 걷기**: 오늘 목록(서랍 포함) 업무 줄과 프로젝트 상세 진행할 업무 줄은 좁은 폭에서 ⋯ 하나만(내일·나중에·오늘로·오늘 할게요 버튼 숨김). CSS로 되면 CSS로.
2. **줄 누름 = 시트 열기**: 좁은 폭에서 줄 아무 데나(제목·빈 자리·상태말) 누르면 그 업무 시트(panelOpen). 체크박스·체크 칸 빈 여백·원문 링크·⋯·버튼·입력칸에서 온 누름은 제외. **여러 개 선택 중에는 줄 누름 = 선택**(지금 제목 누름과 같은 분기). 줄에 tabindex를 새로 주지 않는다(키보드는 지금처럼 제목 Enter).
3. **시트 발**: `내일`·`나중에`·`오늘로`를 누르면 옮긴 뒤 시트를 닫는다(완료로 표시처럼). 밀린 업무(줄에 `오늘 할게요`가 뜨던 조건 그대로)면 발에 `오늘 할게요`를 더한다. 좁은 폭에서 버튼이 두 줄로 내려가는 건 허용(사용자 결정).
4. **시트 가림막**: 좁은 폭 시트가 열리면 뒤에 `--scrim` 판, 판을 누르면 닫힘. 시트 뒤 목록이 눌리지 않아야 한다. 닫히면 초점은 연 줄 제목으로, 줄이 옮겨져 사라졌으면 다음 줄 제목(없으면 목록 머리).
5. **휴대폰 되돌리기 버튼**: 누르는 화면(`matchMedia('(hover: none) and (pointer: coarse)')`)에서는 완료·내일·나중에·오늘로 알림에 `⌘Z/Ctrl+Z로 되돌리기` 글자 대신 `되돌리기` 버튼(→ 기존 replayUndo 경로). **showNotice 정의는 그대로** — 부르는 쪽이 action 인자로 넘기거나, 힌트 글자는 CSS로 숨기는 식. 방법이 showNotice 수정 없이는 안 되면 멈추고 보고.
6. **누르는 자리**: 좁은 폭에서 체크박스·⋯ 누르는 자리 38px 이상(모양 그대로, 투명 `::after`만 넓힘).
7. **문서**: DESIGN.md(업무 줄 ≤520 항목, 상세 시트 발이 시트에서는 붙박이가 아니라는 사실도 바로잡기, Do 목록의 "520px 이하에서는 항상 보이게"), README 해당 절.

## 예외 상황 (테스트로 고정)
1. 넓은 폭: 줄 누름·버튼·hover 동작 변화 없음
2. 좁은 폭: 줄에 동작 버튼 없음, ⋯ 있음
3. 줄 누름 → 시트, 체크박스/원문/⋯/체크 칸 여백 → 시트 안 열림
4. 여러 개 선택 중 줄 누름 → 선택
5. 시트 내일·나중에·오늘로 → 옮기고 닫힘, 완료로 표시 → 지금처럼 닫힘
6. 밀린 업무 시트 → 오늘 할게요 있음, 아닌 업무 → 없음
7. 가림막 누름 → 닫힘, 초점 복귀(사라진 줄이면 다음 줄)
8. 누르는 화면 알림 → 되돌리기 버튼, 마우스 화면 → 지금 글자 그대로
9. showNotice·request·pushUndo 등 안전장치 정의 불변
