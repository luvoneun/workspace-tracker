# 슬랙 연결: 이미 있는 채널 이름이면 그 채널을 쓰기

## 세 줄
- **왜**: 동료 제보 — 위저드 ②에서 `고른 채널 N개 만들어 주기`를 누르면 예전 시도로 만들어 둔 채널(eren-jang-todo 등) 때문에 `이미 있는 이름이에요`로 막다른 길이 된다.
- **기대 변화**: 이름이 이미 있어도 **내가 들어가 있는 내 채널이면 그 채널을 그대로 연결**하고, ③ 확인에서 읽히는지만 본다. 남의 채널·보관된 채널이면 이유를 분명히 알려 준다.
- **성공 기준**: 이미 있는 내 채널(비공개 포함)로 연결까지 끝남 · 남의 채널·보관 채널은 다른 문구 · 새로 만든 채널 동작은 그대로 · 테스트 전부 통과(개수 늘어남).

## 시작 전 (필수)
- `git rev-parse --show-toplevel`이 `/Users/luvon/personal` 그 자체면 멈춤. 아니면 `git log --oneline -1 main`의 main 끝으로 `git merge --ff-only`(fbf6e69 이후 최신 — 실패하면 멈추고 보고). 커밋 금지.
- 이 명세를 worktree의 `docs/정리/2026-09-29-슬랙-이미-있는-채널.md`로 복사.
- 먼저 읽기: `AGENTS.md`, `DECISIONS.md`(슬랙 채널 관련 줄 — 채널은 보관·삭제하지 않음, off/since), `integrations.js`(`slackCreateChannel`·채널 저장·`since`·`slackCheckChannel`·`slack_unreachable` 구분), `routes-integrations.js`(`/api/integrations/slack-channel`), `settings-ui.js`의 연동 › 슬랙 위저드 ②·③과 채널 고르기, 관련 테스트.
- **다른 세션이 settings-ui.js의 앱 탭·checkin·usage 쪽을 곧 건드릴 수 있다 — 슬랙 위저드 자리만 고친다.** update.sh·setup.sh·release.sh·slack-collect.js는 건드리지 않는다.

## 할 일
1. **서버(`integrations.js`)**: 채널 만들기가 `name_taken`이면 `conversations.list`(types=`public_channel,private_channel`, `exclude_archived=false`, limit 200, `cursor`로 넘김 — **최대 10쪽·전체 8초 제한**)로 같은 이름(대소문자·앞 `#` 무시)을 찾는다.
   - 찾았고 `is_archived`면 → `{ok:false, code:'archived'}` "보관된 채널이에요 — 슬랙에서 보관을 풀거나 다른 이름을 적어 주세요".
   - 찾았고 내가 멤버(`is_member`)면 → `{ok:true, id, name, existing:true}` — 새로 만들지 않는다.
   - 못 찾았거나(내가 볼 수 없는 남의 비공개 채널) 멤버가 아니면 → 지금처럼 `name_taken` "다른 사람이 쓰는 이름이에요 — 다른 이름을 적어 주세요".
   - 목록 조회가 제한(쪽수·시간)에 걸리거나 실패하면 → `slack_unreachable`류 "슬랙에서 채널을 다 찾지 못했어요 — 잠시 뒤 다시 눌러 주세요"(이름 중복과 구분).
   - 권한은 이미 받은 `groups:read`·`channels:read`로 충분한지 확인(부족하면 `missing_scope` 안내 — 기존 문구 재사용). 토큰 값은 응답·로그에 없음.
2. **since**: 이미 있는 채널을 쓰게 되면 `since`는 **연결하는 지금**(새로 만든 채널과 같은 규칙 — 그 채널에 예전에 쌓인 메시지를 한꺼번에 가져오지 않게).
3. **같은 채널을 두 칸에**: 고른 두 칸이 같은 채널로 풀리거나, 이미 다른 칸(off 포함)에 연결된 채널이면 → 그 줄에 "이미 ○○ 칸에 연결된 채널이에요 — 다른 이름을 적어 주세요".
4. **화면(`settings-ui.js` 위저드 ②·③, 채널 고르기)**: 이미 있는 내 채널로 풀린 줄은 에러 대신 초록 `✓ 이미 있는 #이름 채널을 쓸게요`. 부분 성공 유지(만든 것·찾은 것은 그대로, 실패 줄만 다시). ③ 확인은 지금처럼 채널마다 실제로 읽어 보고 `✓ #이름 · 할 일 · 잘 읽혀요`. 채널 고르기(⋯)에서도 같은 규칙.
5. **문서**: 앱 README·`docs/연동.md` 슬랙 절에 한 줄, 도움말 문답이 있으면 "이미 있는 이름이라고 나와요" 한 줄(260자 이하 규칙).

## 예외 상황 (테스트로 고정)
1. 이미 있는 내 비공개 채널 → 만들지 않고 연결, since=지금
2. 이미 있는 남의 채널(목록에 없음 또는 멤버 아님) → name_taken 문구
3. 보관된 같은 이름 → archived 문구
4. 목록이 여러 쪽 → 끝까지(상한 10쪽), 상한·시간 초과 → "다 찾지 못했어요"(이름 중복과 구분)
5. 두 칸이 같은 채널 / 이미 다른 칸에 연결된 채널 → 막음
6. 슬랙 연결 실패 → slack_unreachable
7. 기존 새로 만들기 흐름·부분 실패·다시 누르면 남은 것만 → 그대로
