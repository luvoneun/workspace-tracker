## 할 일
1. **상태 점 + 짧은 말**(모든 카드 같은 자리, 같은 크기 — 시안의 10px 점 + 링):
   - 연결 안 됨: 회색 빈 원, 말 없음, 옆에 `연결하기`(지금 그대로).
   - 연결됨, 첫 읽기 전: 흐린 초록 + `연결됨 · 곧 읽어요`(천천히 숨 쉬는 움직임, `prefers-reduced-motion`이면 멈춤).
   - 연결됨: 초록 `연결됨`. 회의록을 직접 옮기는 방식이면 초록 `직접 옮기기`.
   - 늦어요(한 번 실패·예정보다 늦음 — 지금 앱의 판단 기준 재사용): 주황 `늦어요` + `다시 시도`.
   - 멈췄어요(계속 실패·토큰 문제 — 지금 앱의 판단 기준 재사용): 빨강 `멈췄어요` + `다시 연결`.
   - 색만으로 구분하지 않는다(말이 늘 같이). 점은 장식이면 `aria-hidden`, 말은 읽힌다.
2. **버튼 규칙**: 잘 될 때 버튼 없음. `지금 가져오기`는 ⋯ 메뉴의 `새로 받기`로 옮긴다. 한 번 실패 = `다시 시도`(지금 가져오기와 같은 동작), 계속 실패·토큰 문제 = `다시 연결`(지금의 다시 연결 흐름).
3. **⋯ 메뉴**(시안 순서): 새로 받기 / 최근 기록 / 채널 고르기(슬랙) / **슬랙 정리 방식**(지금 이름 `정리 방식` → `슬랙 정리 방식`으로 바꾸기 — 사용자 결정, 카드 안 `· 정리 방식` 링크 문구도 같이) / 다시 연결 / 해제…. 카드마다 해당 없는 것은 빠진다.
4. **맨 위 요약 줄**도 같은 점·말을 쓴다(시안대로).
5. **각 탭 위 표시는 넣지 않는다**(사용자 결정).
6. 실패 이유 줄(`settingsFailWhy`)·최근 기록·원문 모드 주의 한 줄은 지금 동작 유지.
7. **문서**: 앱 README 설정 › 연동 절, 도움말 문답에 `지금 가져오기`를 언급한 곳이 있으면 `⋯ › 새로 받기`로(260자 규칙), `DESIGN.md`에 상태 점 부품 한 줄.
