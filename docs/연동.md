# 연동 상세

`설정 > 연동`에서 하나씩 켜요. 아무것도 안 켜도 앱은 그대로 동작해요 — 할 일·확인 대기·결정·아이디어를 직접 적으면 돼요.

| 연동 | 누구나 되나요 | Claude Code가 필요한가요 |
|---|---|---|
| 지라 | 네 | 아니요 |
| 슬랙 수집 | — | 네 (Claude 없이 도는 기본 수집은 준비 중) |
| 캘린더 | — | 네 |
| 회의록(직접 옮겨서) | 네 | 아니요 |
| 회의록(티로) | — | 네 |

Claude Code가 필요한 항목은 이 맥에 [Claude Code](https://claude.com/claude-code)를 설치하고, 대화에서 `/mcp`로 해당 서비스를 한 번 연결해 둬야 해요(계정 단위 연결이라 앱 설정 파일로는 옮겨지지 않아요).

카드는 **슬랙 수집 → 지라 → 캘린더 → 회의록** 차례로 접혀 있고, `연결하기`를 누른 카드만 그 자리에서 **한 단계씩** 펼쳐져요(끝낸 단계는 `① 토큰 ✓`처럼 한 줄로 접혀요). 연결된 카드는 무엇이 되고 있는지 한 줄(예: `● ○○님 · 회사.atlassian.net · 3분 전 읽음`)과 `⋯`만 보여요. 끊고 싶으면 `⋯ › 해제…` → 카드 안 확인 줄의 `해제`예요(토큰 파일은 남아요).

## 지라

1. **① 토큰** — `토큰 만들기 ↗`를 눌러 Atlassian 계정 보안 페이지에서 **API 토큰 만들기** → 이름은 아무거나 → **복사**, 그 칸에 붙여 넣고 `다음`.
2. **② 계정** — `지라에 로그인하는 이메일`만 적어요. 지라 주소는 팀 설정이 있으면 묻지 않아요(`지라 주소는 팀 설정(회사.atlassian.net)을 써요 · 바꾸기`). 팀 설정이 없으면 주소 칸(예: `https://회사.atlassian.net`)이 같은 단계에 보여요.
3. **③ 확인** — `연결`을 누르면 앱이 지라에 한 번 물어봐서 확인하고 `○○님으로 연결됐어요`라고 표시 이름만 알려 줘요(토큰·이메일은 화면 어디에도 다시 나오지 않아요).

토큰을 바꾸려면 지라 카드의 `⋯ › 다시 연결(토큰 바꾸기)`예요.

**앱이 지라와 무엇을 주고받나요** — 지라에는 아무것도 몰래 쓰지 않아요. 앱이 하는 일은 이 넷뿐이에요.

- **담당 티켓 읽기**: 프로젝트 목록·지라 띠 카드·하위 티켓이 여기서 와요(제 담당 티켓과 연결해 둔 티켓만 읽어요).
- **상태·배포 버전·기한 바꾸기**: 프로젝트 화면에서 직접 바꿀 수 있지만, 바꾸기 전에 **전 → 후를 보여 주는 확인 줄**을 한 번 더 거쳐요. 실행 취소(⌘Z)는 안 돼요 — 확인 줄이 그 안전장치예요.
- **에픽 만들기**: 새 프로젝트 화면에서 이름과 직군을 고르면 에픽과 직군별 하위 티켓을 만들어요. 이것도 만들기 전에 목록을 보여 주고 한 번 더 물어봐요.
- **내 댓글 알림**: 오늘 탭 맨 위 `반응 필요`가 제가 담당·보고·지켜보는 티켓 중 제 마지막 댓글 뒤에 남이 단 댓글을 모아 보여 줘요.

## 슬랙 수집

팀 슬랙 앱 하나를 워크스페이스에 설치해 두고, 쓰는 사람마다 **본인 토큰**을 받아서 써요(모두가 같은 토큰을 쓰지 않아요).

`설정 > 연동 > 슬랙 수집`의 `연결하기`를 누르면 **① 토큰 → ② 채널 → ③ 확인**이 한 단계씩 나와요.

1. **① 토큰** — `토큰 받는 곳 열기 ↗`를 누르면 팀 슬랙 앱 페이지가 새 탭으로 열려요(영어 화면이에요). 왼쪽 **OAuth & Permissions** → **Install to Workspace**(이미 했으면 Reinstall) → 허용. 토큰이 두 개 보이는데, **`xoxp-`로 시작하는 User OAuth Token** 옆 **Copy**예요. `xoxb-`로 시작하는 Bot 토큰을 붙이면 앱이 바로 알려 줘요.
   (캡처 예정 — ![토큰 복사](img/slack-1.png))
   페이지가 안 열리거나 권한이 없다고 나오면 이 앱의 `Collaborator`로 아직 추가되지 않은 거예요 — `만든 사람에게 요청 문구 복사`를 눌러 만든 사람에게 보내 주세요. 붙여 넣은 토큰은 ●●●로 가려지고, `다음`을 누르면 앱이 토큰이 맞는지만 확인해요.
2. **② 채널** — 슬랙에 공유한 메시지를 **어디로 받을지** 골라요. `할 일`(필수)·`기다리는 것`·`정해진 것`·`언젠가` 중 고른 만큼 **나만 있는 비공개 채널을 앱이 만들어 줘요**(기본 이름 `my-todo`·`my-waiting`·`my-align`·`my-someday`, 바꿔도 돼요). `고른 채널 N개 만들어 주기` 한 번이면 돼요. 같은 이름이 이미 있으면 그 줄에 `이미 있는 이름이에요 — 다른 이름을 적어 주세요`라고 나오니 이름만 바꿔 다시 누르면 돼요(이미 만든 채널은 그대로 있어요). 팀 슬랙 앱에 채널 만들기 권한이 없으면 만든 사람에게 권한 추가를 요청해 주세요.
3. **③ 확인** — `✓ #my-todo · 할 일 · 잘 읽혀요`와 **슬랙에서 이렇게 보내요**를 확인하고 `연결`을 눌러요.

**슬랙에서 이렇게 보내요**

1. **남의 메시지**는 메시지에 마우스를 올려 **⋯ → 전달**(또는 **공유**) → 받는 곳에 **#my-todo**처럼 쓸 채널을 골라 보내요.
2. 전달할 때 **메모 한 줄**을 같이 적으면(예: "금요일까지 답하기") 할 일 문구에 참고해요.
3. **내 생각**은 그 채널에 그냥 적어도 돼요 — 한 메시지가 한 항목이에요.
4. 어디로 보낼지: 해야 할 일 → **할 일** · 누가 답해 줘야 하는 것 → **기다리는 것** · 정해진 정책 → **정해진 것** · 참고거리 → **언젠가**

스레드 댓글을 전달하면 스레드 전체를 읽어 맥락을 잡아요. 같은 안내는 연결된 슬랙 카드의 `⋯ › 보내는 법`과 `설정 > 도움말`에도 있어요.

채널 이름은 슬랙에서 바꿔도 그대로 이어져요(앱이 연동 탭을 열 때 새 이름을 따라가요). 채널을 지웠거나 보관하면 카드에 `#이름 채널을 읽지 못했어요 · 채널 고치기`가 떠요. 받을 곳을 나중에 더하려면 `⋯ › 채널 고치기`(이미 연결된 채널은 그대로 두고 더하기만 해요), 토큰을 바꾸려면 `⋯ › 다시 연결(토큰 바꾸기)`예요.

**메시지를 채널에 공유(포워드)하거나 직접 적으면, 그게 곧 "이건 할 일이다"라는 표시예요.** 채널을 읽어 할 일로 옮기는 일은 지금은 Claude Code가 자동화로 돌며 해요(스레드까지 읽어 맥락을 파악하고 문구를 다듬어요). Claude Code 없이 도는 기본 수집(메시지 1개 = 할 일 1개)은 준비 중이에요 — 그때까지 Claude Code가 없으면 채널을 연결해도 할 일이 들어오지 않아요.

**피그마·기타 알림**: 앱이 피그마를 직접 읽어 오지는 않지만, 피그마의 슬랙 알림(댓글·멘션 등)을 이 채널에 공유하면 슬랙 수집을 통해 그대로 할 일로 들어와요 — 사실상 슬랙을 거쳐 들어오는 셈이에요. 필요한 것은 위 슬랙 수집(지금은 Claude Code 포함)뿐이에요. (오늘 탭의 `반응 필요`가 보여 주는 지라 댓글과는 다른 길이에요 — 그건 앱이 지라를 직접 읽어요.)

**토큰은 채팅·메일로 보내지 말고 앱의 그 칸에만 붙여 넣어 주세요.**

## 캘린더

`연결하기`를 누르면 길이 둘 보여요.

- **비밀 주소 붙이기(누구나)** — 구글 캘린더의 비밀 주소(iCal)를 붙이는 길이에요. **곧 돼요**(지금은 자리만 있어요).
- **Claude Code로** — Claude Code(유료 구독)가 있어야 해요.
  1. claude.ai 설정 → 커넥터 → Google Calendar 연결(주소 `claude.ai/settings/connectors`는 `복사`로)
  2. Claude Code에서 `/mcp` → 로그인
  3. 여기서 `켜기`

## 회의록

기본은 **직접 옮기기**예요 — 회의가 끝나면 회의 탭의 정리 화면에 내용을 붙여 넣으면 돼요(아무것도 설치하지 않아요). 티로 회의록을 초안으로 받고 싶으면 회의록 카드의 `바꾸기` → `티로`를 골라요(Claude Code(유료 구독)가 있어야 해요).

1. 터미널에 붙여 넣기: `claude mcp add --transport http tiro-mcp https://mcp.tiro.ooo/mcp`(`복사` 버튼이 있어요)
2. Claude Code에서 `/mcp` → `tiro-mcp` → `Authenticate`
3. 여기서 `티로로 받기`

캘린더 연결이 없어도 프로젝트는 직접 만든 이름으로 쓸 수 있어요.

## 다른 앱을 쓰면

앱 코드를 고칠 필요는 없어요. 아래 모양으로 파일을 채우거나 API를 부르면, 슬랙·구글 캘린더·티로가 아닌 다른 도구를 써도 그대로 동작해요.

**스냅샷 파일 둘(통째로 덮어써도 돼요)**

- `tracker/calendar_today.md` — 오늘 탭의 `오늘 미팅` 카드가 읽어요.
  ```markdown
  # 오늘 캘린더 일정

  마지막 갱신: YYYY-MM-DD

  - 14:40-15:00 | 과금 유저 우대 논의
  - 15:00-16:00 | PMO 정기 회의
  ```
- `tracker/jira_issues.md` — 프로젝트를 고르는 목록이 읽는 대비책 파일이에요(앱이 지라를 직접 읽지 못할 때만 쓰여요).
  ```markdown
  # 지라 이슈 (내 담당, 진행중/백로그)

  마지막 갱신: YYYY-MM-DD

  - IO-45438 | 에픽 | 진행 중 | 보드 AI
  - IO-36600 | 에픽 | Backlog | 게시판 모아보기 기능 추가
  ```

**회의 초안 파일(끝에 추가만 해요)**

- `tracker/meeting_drafts.json` — 회의 정리 화면의 "AI가 분류한 것" 초안이에요. 형식은 `tracker/inbox-app/README.md`와 `.claude/skills/tiro-sync.md`를 참고해요(사람이 검수해서 `담기`를 눌러야 실제 목록에 들어가요).

**할 일·확인 대기·결정·아이디어는 파일을 직접 쓰지 않아요.** 대신 다음 명령 한 줄로 등록해요(서버가 켜져 있어야 해요) — 앱과 같은 검증·저장 규칙을 타는 유일한 길이에요.

```sh
node tracker/inbox-app/import-record.js item '{"type":"task","description":"정리한 한 줄","permalink":"https://원본 링크"}'
```

`type`은 `task`(할 일)·`check`(확인 대기)·`decision`(결정)·`idea`(아이디어) 중 하나, `permalink`는 그 도구에서 만든 `https://` 원문 링크예요(같은 링크로 다시 보내면 중복으로 걸러져요). `priority`·`jira`·`group`·`who`·`project`·`due`는 선택이에요.

**이 모양으로 넣으면 어떤 앱이든 돼요.** 새 도구를 붙이는 스킬(수집 지시서)이 필요하면 `설정 > 연동` 맨 아래 `다른 도구를 쓰고 있어요 → 요청하기`(도구 이름을 적으면 요청문이 클립보드에 복사돼요)나 슬랙 DM으로 요청해 주세요.
