# 연동 상세

`설정 > 연동`에서 하나씩 켜요. 아무것도 안 켜도 앱은 그대로 동작해요 — 할 일·확인 대기·결정·아이디어를 직접 적으면 돼요.

| 연동 | 누구나 되나요 | Claude Code가 필요한가요 |
|---|---|---|
| 지라 | 네 | 아니요 |
| 슬랙 수집 | 네 (원문 그대로) | 선택 (문구 다듬기) |
| 캘린더(맥 캘린더) | 네 | 아니요 |
| 캘린더(비밀 주소) | 네 | 아니요 |
| 캘린더(Claude Code로) | — | 네 |
| 회의록(직접 옮겨서) | 네 | 아니요 |
| 회의록(티로) | — | 네 |

Claude Code가 필요한 항목은 이 맥에 [Claude Code](https://claude.com/claude-code)를 설치해 둬야 해요. 캘린더(Claude Code로)·티로는 대화에서 `/mcp`로 해당 서비스를 한 번 연결해 둬야 하고(계정 단위 연결이라 앱 설정 파일로는 옮겨지지 않아요), 슬랙 수집은 `/mcp` 연결이 필요 없어요 — 슬랙은 앱이 토큰으로 직접 읽어요.

카드는 **슬랙 수집 → 지라 → 캘린더 → 회의록** 차례로 접혀 있고, `연결하기`를 누른 카드만 그 자리에서 **한 단계씩** 펼쳐져요(끝낸 단계는 `① 토큰 ✓`처럼 한 줄로 접혀요). 연결된 카드는 무엇이 되고 있는지 한 줄(예: `● ○○님 · 회사.atlassian.net · 3분 전 읽음`)과 `⋯`만 보여요. 끊고 싶으면 `⋯ › 해제…` → 카드 안 확인 줄의 `해제`예요(토큰 파일은 남아요).

## 지라

1. **① 토큰** — `토큰 만들기 ↗`를 눌러 Atlassian 계정 보안 페이지에서 **API 토큰 만들기** → 이름은 아무거나 → **복사**, 그 칸에 붙여 넣고 `다음`.
2. **② 계정** — `지라에 로그인하는 이메일`만 적어요. 지라 주소는 팀 설정이 있으면 묻지 않아요(`지라 주소는 팀 설정(회사.atlassian.net)을 써요 · 바꾸기`). 팀 설정이 없으면 주소 칸(예: `https://회사.atlassian.net`)이 같은 단계에 보여요. 브라우저 주소창의 주소를 통째로 붙여도 앱이 앞부분(`https://회사.atlassian.net`)만 남겨요(`https://`를 빼고 적어도 붙여 줘요).
   - 연결이 안 되면 이유가 한 줄로 나와요: `이메일 모양이 아니에요`(이메일 칸) · `이메일이나 토큰이 맞지 않아요`(지라는 둘 중 무엇이 틀렸는지 알려 주지 않아요 — 이메일부터 보고, 맞으면 ← 이전에서 새 토큰) · `지라에 연결하지 못했어요`(주소·인터넷 연결).
3. **③ 확인** — `연결`을 누르면 앱이 지라에 한 번 물어봐서 확인하고 `○○님으로 연결됐어요`라고 표시 이름만 알려 줘요(토큰은 화면 어디에도 다시 나오지 않아요 — 이메일은 다시 연결할 때 칸에 미리 채워져 있어요).

토큰을 바꾸려면 지라 카드의 `⋯ › 다시 연결(토큰 바꾸기)`예요.

**앱이 지라와 무엇을 주고받나요** — 지라에는 아무것도 몰래 쓰지 않아요. 앱이 하는 일은 이 넷뿐이에요.

- **담당 티켓 읽기**: 프로젝트 목록·지라 띠 카드·하위 티켓이 여기서 와요(제 담당 티켓과 연결해 둔 티켓만 읽어요).
- **상태·배포 버전·기한 바꾸기**: 프로젝트 화면에서 직접 바꿀 수 있지만, 바꾸기 전에 **전 → 후를 보여 주는 확인 줄**을 한 번 더 거쳐요. 실행 취소(⌘Z)는 안 돼요 — 확인 줄이 그 안전장치예요.
- **에픽 만들기**: 새 프로젝트 화면에서 이름과 직군을 고르면 에픽과 직군별 하위 티켓을 만들어요. 이것도 만들기 전에 목록을 보여 주고 한 번 더 물어봐요.
- **내 댓글 알림**: 오늘 탭 맨 위 `반응 필요`가 제가 담당·보고·지켜보는 티켓 중 제 마지막 댓글 뒤에 남이 단 댓글을 모아 보여 줘요.

## 슬랙 수집

**가장 쉬운 길**: `설정 > 연동 > 슬랙 수집`의 `연결하기`를 누르고 `슬랙 연결` 버튼을 누르면 새 탭에 슬랙 화면이 열려요. 거기서 `허용`만 누르면 끝이에요(1분). 토큰을 복사하지 않아도 되고, 연결은 앱이 알아서 이어 가요. 허용이 끝나면 아래 **② 채널**부터 이어져요.

- 연결이 풀리면(슬랙에서 앱을 지웠거나 오래 꺼 둔 경우) 카드에 `슬랙 연결이 풀렸어요 — 다시 연결 한 번이면 돼요`가 떠요. `다시 연결`을 한 번 누르고 `허용`하면 돼요.
- 슬랙에서 `회사 슬랙이 이 앱을 막았어요 — 관리자에게 물어봐 주세요`나 `아직 허용이 끝나지 않았어요`가 나오면 회사 슬랙 관리자의 승인이 필요한 거예요.
- 다른 기기(폰·다른 맥)에서 열면 버튼이 회색이에요 — `슬랙 연결은 앱을 설치한 맥에서 해 주세요.`
- 이전에 토큰을 붙여 넣어 연결한 분은 그대로 돌아요. 바꾸고 싶으면 `⋯ › 새 방식으로 다시 연결 (자동 갱신)`이에요.

**토큰을 직접 붙여 넣으려면** 카드 안의 `고급: 토큰 직접 붙여 넣기`를 펴요. 쓰는 사람마다 **본인 토큰**을 받아서 쓰고(모두가 같은 토큰을 쓰지 않아요), 아래 순서 그대로예요 — **① 토큰 → ② 채널 → ③ 확인**이 한 단계씩 나와요.

1. **① 토큰** — `토큰 받는 곳 열기 ↗`를 누르면 팀 슬랙 앱의 **OAuth & Permissions** 화면이 새 탭으로 열려요(영어 화면이에요 — 다른 화면이면 왼쪽 메뉴에서 골라요). **Install to (회사 슬랙 이름)** 버튼(이미 했으면 **Reinstall to …**) → **허용(Allow)**. 토큰이 두 개 보이는데, **`xoxp-`로 시작하는 User OAuth Token** 옆 **Copy**예요. `xoxb-`로 시작하는 Bot 토큰을 붙이면 앱이 바로 알려 줘요.
   (캡처 예정 — ![토큰 복사](img/slack-1.png))
   페이지가 안 열리거나 권한이 없다고 나오면 이 앱의 `Collaborator`로 아직 추가되지 않은 거예요 — `만든 사람에게 요청 문구 복사`를 눌러 만든 사람에게 보내 주세요. 붙여 넣은 토큰은 ●●●로 가려지고, `다음`을 누르면 앱이 토큰이 맞는지만 확인해요.
2. **② 채널** — 슬랙에 공유한 메시지를 **어디로 받을지** 골라요. `할 일`·`기다리는 것`·`정해진 것`·`언젠가` 중 **하나 이상** 고른 만큼(처음엔 할 일·기다리는 것이 체크돼 있고 둘 다 풀 수 있어요) **나만 있는 비공개 채널을 앱이 만들어 줘요**(기본 이름은 슬랙 사용자 이름을 앞에 붙인 `<이름>-todo`·`-waiting`·`-align`·`-someday`, 바꿔도 돼요). `고른 채널 N개 만들어 주기` 한 번이면 돼요. 같은 이름이 이미 있어도 **내가 들어가 있는 내 채널**(예전에 만들어 둔 것)이면 새로 만들지 않고 그 채널을 그대로 써요(`✓ 이미 있는 #이름 채널을 쓸게요` — 연결한 때부터 읽어요). 다른 사람이 쓰는 이름이거나 보관된 채널, 이미 다른 칸에 연결된 채널이면 그 줄에 이유가 나오니 이름만 바꿔 다시 누르면 돼요(이미 만든 채널은 그대로 있어요). 팀 슬랙 앱에 채널 만들기 권한이 없으면 만든 사람에게 권한 추가를 요청해 주세요.
3. **③ 확인** — `✓ #<내 이름>-todo · 할 일 · 잘 읽혀요`와 **슬랙에서 이렇게 보내요**를 확인하고 `연결`을 눌러요.

**슬랙에서 이렇게 보내요**

1. **남의 메시지**는 메시지에 마우스를 올려 **⋯ → 전달**(또는 **공유**) → 받는 곳에 **#<내 이름>-todo**처럼 쓸 채널을 골라 보내요.
2. 전달할 때 **메모 한 줄**을 같이 적으면(예: "금요일까지 답하기") 할 일 문구에 참고해요.
3. **내 생각**은 그 채널에 그냥 적어도 돼요 — 한 메시지가 한 항목이에요.
4. 어디로 보낼지: 해야 할 일 → **할 일** · 누가 답해 줘야 하는 것 → **기다리는 것** · 정해진 정책 → **정해진 것** · 참고거리 → **언젠가**

스레드 댓글을 전달하면 스레드 전체를 읽어 맥락을 잡아요. 같은 안내는 연결된 슬랙 카드의 `⋯ › 보내는 법`과 `설정 > 도움말`에도 있어요.

채널 이름은 슬랙에서 바꿔도 그대로 이어져요(앱이 연동 탭을 열 때 새 이름을 따라가요). 채널을 지웠거나 보관하면 카드에 `#이름을 찾을 수 없어요 — 슬랙에서 지웠거나 보관했어요 · 채널 고르기`가 떠요(켜 둔 채널이 **모두** 사라졌으면 수집이 멈춘 것과 같아서 빨간 줄이에요). 받을 곳을 나중에 더하거나 빼려면 `⋯ › 채널 고르기`예요 — 체크를 풀면 앱이 그 채널을 더 이상 읽지 않고(슬랙 채널과 이미 들어온 항목은 그대로), 다시 체크하면 **그때부터** 읽어요(뺀 동안 온 메시지는 가져오지 않아요). `할 일`도 뺄 수 있지만 **마지막 하나**는 뺄 수 없어요 — 슬랙 수집을 통째로 끄려면 `⋯ › 해제`예요. 연결된 채널의 이름은 여기서 바꾸지 않고 슬랙에서 바꿔요. 토큰을 바꾸려면 `⋯ › 다시 연결(토큰 바꾸기)`예요.

이 채널들은 나만 있는 채널로 써요 — 다른 사람을 초대하면 그 사람이 쓴 메시지도 할 일로 들어와요.

**메시지를 채널에 공유(포워드)하거나 직접 적으면, 그게 곧 "이건 할 일이다"라는 표시예요.** 채널과 원본 스레드는 앱의 수집 스크립트가 읽어 오고 저장도 스크립트가 해요. 문구를 어떻게 넣을지는 카드의 `⋯ › 슬랙 정리 방식`에서 골라요.

- **Claude로 다듬기** — Claude Code가 내용을 받아 맥락을 파악하고 문구만 다듬어요(명령을 실행하거나 파일을 읽지 않아요). 이 맥에 Claude Code(유료 구독)가 있어야 해요.
- **원문 그대로** — Claude 없이 **메시지 1개 = 항목 1개**로, 요약하지 않고 메시지 첫 줄을 그대로 넣어요(첫 줄이 인사말처럼 짧으면 다음 줄까지, 전달하며 적은 메모는 ` — 메모`로 뒤에, 200자까지). 슬랙 표기(@사람·#채널·링크·굵게·그림 글자)는 읽는 글로 바꾸고, 글 없이 파일만 있으면 `(파일) 이름`이에요. 어느 채널에 보냈는지로 할 일·기다리는 것·정해진 것·언젠가가 정해지고(담당자·기한은 넣지 않아요 — 필요하면 앱에서 정해요). **기한은 넣지 않고**(원문에 날짜가 있어도), 비슷한 일 거르기도 하지 않아요(같은 메시지 링크만 걸러요). 문구가 길거나 정확하지 않을 수 있으니 필요하면 앱에서 고쳐 주세요.

처음 연결할 때 이 맥에 Claude Code가 없으면 **원문 그대로**, 있으면 **Claude로 다듬기**로 시작해요(예전에 연결한 사람은 그대로 Claude로 다듬기예요). 방식을 바꿔도 이미 들어온 항목은 그대로예요. Claude로 다듬는 중인데 Claude Code가 없거나 로그인이 풀려 멈추면 카드에 `원문 그대로로 바꾸기`가 떠요(저절로 바뀌지는 않아요 — 멈춘 동안 온 메시지는 다시 돌면 들어와요).

**피그마·기타 알림**: 앱이 피그마를 직접 읽어 오지는 않지만, 피그마의 슬랙 알림(댓글·멘션 등)을 이 채널에 공유하면 슬랙 수집을 통해 그대로 할 일로 들어와요 — 사실상 슬랙을 거쳐 들어오는 셈이에요. 필요한 것은 위 슬랙 수집뿐이에요(원문 그대로면 Claude Code도 필요 없어요). (오늘 탭의 `반응 필요`가 보여 주는 지라 댓글과는 다른 길이에요 — 그건 앱이 지라를 직접 읽어요.)

**토큰은 채팅·메일로 보내지 말고 앱의 그 칸에만 붙여 넣어 주세요.**

### 슬랙 수집이 "자동 분류기가 막음"·출력 없이 실패로 멈췄다면

예전에는 Claude Code가 슬랙을 읽는 명령을 직접 실행했는데, Claude Code 버전에 따라 그 명령이 막히거나(허용 규칙) 명령이 설치 폴더 밖의 슬랙 토큰 파일을 못 읽어(샌드박스) 채널 넷이 모두 멈추는 맥이 있었어요. 지금은 앱의 스크립트가 슬랙을 읽고 저장하고, Claude Code는 도구 없이 문구만 정리해서 이 문제가 생기지 않아요. 설정 › 앱 › `업데이트 받기`(또는 `업데이트.command`)로 새 버전을 받으면 돼요. 설정 › 연동 › 슬랙 ⋯ › `최근 기록`의 시각 옆 `v1.1.2` 같은 글자가 그 회차를 돌린 앱 버전이에요.

### 슬랙 수집이 "OAuth session expired and could not be refreshed"로 실패하면

메시지를 할 일 문구로 정리하는 단계는 이 맥의 Claude Code가 해요. 터미널에서는 로그인돼 있는데 백그라운드 자동 실행에서만 로그인 갱신을 못 하는 맥이 있어요. 그럴 때는 오래 가는 토큰을 만들어 앱에 한 번 넣어 두면 돼요. 멈춘 카드에 `Claude Code 로그인이 풀렸어요 — 아래 두 줄이면 다시 돼요`와 두 줄 칸이 떠요(캘린더·회의록도 함께 멈췄으면 그 카드들은 칸이 있는 카드를 가리켜요 — 토큰 하나로 함께 다시 돼요).

1. **① 터미널에서** `claude setup-token` — 카드의 `복사`를 눌러 터미널에 붙여 넣고 Enter → 브라우저에서 허용 → 터미널에 긴 토큰(`sk-ant-oat…`)이 나와요.
2. **② 그 토큰을 복사해** 카드의 칸에 붙여 넣고 `저장` → `새 토큰을 저장했어요 — 다시 시도를 눌러 확인해 주세요`가 떠요. 다른 카드의 `슬랙 수집 카드의 두 줄`을 누르면 그 칸으로 가요.
3. 카드의 `다시 시도`.

터미널에 붙이는 건 `claude setup-token` 한 줄뿐이에요. 토큰을 터미널에 붙여 넣지 마세요(`command not found`가 나와요) — 앱의 칸에 붙여요. 칸에 띄어쓰기·줄바꿈이 섞이면 `토큰 사이에 띄어쓰기나 줄바꿈이 있어요`가 떠요 — 터미널에서 한 줄로 다시 복사해요.

토큰은 이 맥의 파일(`~/.config/workspace-claude-token`, 나만 읽을 수 있게)에만 저장되고 화면·로그·설정 파일 어디에도 다시 나오지 않아요 — 앱도 저장만 하고 다시 보여 주지 않아요. 유료 구독이 있는 계정이어야 해요. 약 1년 뒤 만료되면 같은 두 줄을 한 번 더 해요.

## 캘린더

`연결하기`를 누르면 맨 위에 **맥 캘린더(추천)**, 그 아래 **Claude Code로**, 맨 아래 접힌 **다른 방법: 비밀 주소 붙이기**가 보여요.

- **맥 캘린더(추천)** — Claude·비밀 주소 없이 맥 기본 캘린더 앱에서 읽어요. 회사 구글 계정처럼 비밀 주소가 막힌 계정도 돼요.
  1. 맥 **시스템 설정 → 인터넷 계정 → Google**에서 회사 계정을 추가하고 **캘린더**를 켜요
  2. `허용하고 확인` — 맥이 캘린더 접근을 물으면 **허용**. 잠시 뒤 `캘린더 N개 · 오늘 일정 M개를 읽었어요`가 떠요
  3. 읽을 캘린더를 골라 `이 캘린더로 연결` — 기본은 내 이메일 이름의 캘린더 하나예요(휴일·구독·다른 사람 캘린더는 꺼 두는 걸 권해요)

  연결하면 곧바로 한 번, 그 뒤로 매일 8–20시 30분마다 읽어요(캘린더 앱을 켜지 않고 맥의 캘린더 저장소(EventKit)에서 바로 읽어요 — 반복 일정도 오늘 회차로 들어와요). 고른 캘린더의 제목·시간만 읽고(장소·참석자·메모는 안 읽어요), 종일 일정·취소된 일정·내가 거절한 초대는 오늘 미팅에 넣지 않아요. 연결된 카드에는 `맥 캘린더에서 읽는 중 · 10분 전`이 떠요.
  `맥이 캘린더 접근을 막았어요`가 뜨면 애플 메뉴 › **시스템 설정 › 개인정보 보호 및 보안 › 캘린더**에서 목록의 이름(node·osascript 등 — 맥에 따라 달라요)을 찾아 「전체 접근」으로 켜고, 같은 화면의 **자동화**에서도 캘린더를 켠 뒤 다시 눌러요. 화면에는 찾을 이름의 예시 그림(맥 화면이 아니라 그린 것)이 같이 떠요. 앱이 그 설정 화면을 직접 열 수는 없어요. `맥 캘린더에 구글 계정이 없어요`면 1단계부터 해요. 고른 캘린더가 사라지면 카드에 `고른 캘린더를 찾지 못했어요 — 다시 골라 주세요`가 떠요 — `⋯ › 캘린더 다시 고르기`.
  이 버튼이 `업데이트.command를 한 번 실행하면 쓸 수 있어요`라고 하면 앱을 한 번 업데이트해요(확인을 도는 자동 실행이 새로 생겼어요).

- **다른 방법: 비밀 주소 붙이기(누구나)** — Claude 없이 앱이 직접 읽어요.
  1. 컴퓨터에서 **calendar.google.com** 열기(폰 앱에는 이 설정이 없어요)
  2. 오른쪽 위 **톱니바퀴 → 설정**
  3. 왼쪽 **내 캘린더의 설정**에서 **내 이름**
  4. 아래로 내려 **캘린더 통합 → iCal 형식의 비공개 주소** 옆 **복사**
  5. 카드의 가려진 칸에 붙여 넣고 `연결`

  그 칸이 아예 안 보이면 회사 구글 관리자가 막아 둔 거예요 — 맥 캘린더나 Claude Code로 연결하세요. 내 기본 캘린더만 읽어요(팀 캘린더 같은 다른 캘린더는 안 들어와요).

  앱이 주소를 한 번 읽어 `오늘 일정 3개가 보여요`처럼 알려 준 뒤 저장해요. 그 뒤로는 30분마다(설정 › 연동을 열 때와 새로고침 때도, 5분 넘게 묵었으면) 직접 읽어요. 연결된 카드에는 `비밀 주소로 읽는 중 · 오늘 3개 · 10분 전`이 떠요.
  비밀 주소는 **비밀번호와 같아요** — 이 주소만 있으면 누구나 내 일정을 볼 수 있어요. 채팅·메일로 보내지 말고, 새어 나갔으면 구글 캘린더의 같은 자리에서 `재설정`해 새 주소를 받아 `⋯ › 다시 연결(주소 바꾸기)`로 붙여요. 앱은 주소를 `~/.config/workspace-calendar-ical` 파일(나만 읽기)에만 두고 화면·로그 어디에도 다시 보여 주지 않아요. 종일 일정(휴가 등)은 오늘 미팅에 넣지 않아요.
- **Claude Code로** — Claude Code(유료 구독)가 있어야 해요.
  1. **claude.ai → 설정 → 커넥터**(주소 `claude.ai/settings/connectors`는 `복사`로)에서 Google Calendar → **연결** → 구글 로그인 → **허용**. 이 맥의 Claude Code에 로그인한 계정과 **같은 계정**이어야 해요.
  2. 여기서 `켜기` — 매일 9~19시 2시간마다 읽어요. 바로 확인하려면 연결 뒤 `⋯ › 새로 받기`
  3. 안 되면: 터미널에서 `claude`를 켠 뒤 `/mcp` → 목록에 **claude.ai Google Calendar**가 연결됨인지 확인해요

  연결할 때 "관리자 승인 필요"가 뜨면 회사에서 막아 둔 거예요 — 관리자에게 요청하거나 캘린더 없이 써도 돼요.

  맥 캘린더·비밀 주소 갈래로 읽는 동안에는 Claude로 읽는 자동 갱신(`calendar-sync`)이 돌지 않아요(연결을 저장하면 앱이 등록을 알아서 내려요).

## 회의록

기본은 **직접 옮기기**예요 — 회의가 끝나면 회의 탭의 정리 화면에 내용을 붙여 넣으면 돼요(아무것도 설치하지 않아요). 티로 회의록을 초안으로 받고 싶으면 회의록 카드의 `바꾸기` → `티로`를 골라요(Claude Code(유료 구독)가 있어야 해요).

1. 터미널에 붙여 넣기: `claude mcp add --transport http tiro-mcp https://mcp.tiro.ooo/mcp`(`복사` 버튼이 있어요)
2. Claude Code에서 `/mcp` → `tiro-mcp` → `Authenticate`
3. 여기서 `티로로 받기`

캘린더 연결이 없어도 프로젝트는 직접 만든 이름으로 쓸 수 있어요.

## 다른 앱을 쓰면

앱 코드를 고칠 필요는 없어요. 아래 모양으로 파일을 채우거나 API를 부르면, 슬랙·구글 캘린더·티로가 아닌 다른 도구를 써도 그대로 동작해요.

**스냅샷 파일 둘(통째로 덮어써도 돼요)**

- `tracker/calendar_today.md` — 오늘 탭의 `오늘 미팅` 카드가 읽어요.
  ```markdown
  # 오늘 캘린더 일정

  마지막 갱신: YYYY-MM-DD

  - 14:40-15:00 | 과금 유저 우대 논의
  - 15:00-16:00 | PMO 정기 회의
  ```
- `tracker/jira_issues.md` — 프로젝트를 고르는 목록이 읽는 대비책 파일이에요(앱이 지라를 직접 읽지 못할 때만 쓰여요).
  ```markdown
  # 지라 이슈 (내 담당, 진행중/백로그)

  마지막 갱신: YYYY-MM-DD

  - IO-45438 | 에픽 | 진행 중 | 보드 AI
  - IO-36600 | 에픽 | Backlog | 게시판 모아보기 기능 추가
  ```

**회의 초안 파일(끝에 추가만 해요)**

- `tracker/meeting_drafts.json` — 회의 정리 화면의 "AI가 분류한 것" 초안이에요. 형식은 `tracker/inbox-app/README.md`와 `.claude/skills/tiro-sync.md`를 참고해요(사람이 검수해서 `담기`를 눌러야 실제 목록에 들어가요).

**할 일·확인 대기·결정·아이디어는 파일을 직접 쓰지 않아요.** 대신 다음 명령 한 줄로 등록해요(서버가 켜져 있어야 해요) — 앱과 같은 검증·저장 규칙을 타는 유일한 길이에요.

```sh
node tracker/inbox-app/import-record.js item '{"type":"task","description":"정리한 한 줄","permalink":"https://원본 링크"}'
```

`type`은 `task`(할 일)·`check`(확인 대기)·`decision`(결정)·`idea`(아이디어) 중 하나, `permalink`는 그 도구에서 만든 `https://` 원문 링크예요(같은 링크로 다시 보내면 중복으로 걸러져요). `priority`·`jira`·`group`·`who`·`project`·`due`는 선택이에요.

**이 모양으로 넣으면 어떤 앱이든 돼요.** 새 도구를 붙이는 스킬(수집 지시서)이 필요하면 `설정 > 연동` 맨 아래 `다른 도구를 쓰고 있어요 → 요청하기`(도구 이름을 적으면 요청문이 클립보드에 복사돼요)나 슬랙 DM으로 요청해 주세요.
