# 연동 상세

`설정 > 연동`에서 하나씩 켜요. 아무것도 안 켜도 앱은 그대로 동작해요 — 할 일·확인 대기·결정·아이디어를 직접 적으면 돼요.

| 연동 | 누구나 되나요 | Claude Code가 필요한가요 |
|---|---|---|
| 지라 | 네 | 아니요 |
| 슬랙 수집 | — | 네 (Claude 없이 도는 기본 수집은 준비 중) |
| 캘린더 | — | 네 |
| 회의록(직접 옮겨서) | 네 | 아니요 |
| 회의록(티로) | — | 네 |

Claude Code가 필요한 항목은 이 맥에 [Claude Code](https://claude.com/claude-code)를 설치하고, 대화에서 `/mcp`로 해당 서비스를 한 번 연결해 둬야 해요(계정 단위 연결이라 앱 설정 파일로는 옮겨지지 않아요).

## 지라

1. [id.atlassian.com/manage-profile/security/api-tokens](https://id.atlassian.com/manage-profile/security/api-tokens)에서 `Create API token`으로 토큰을 만들어요.
2. `설정 > 연동 > 지라`에서 `연결하기`를 누르고, 지라 주소(예: `https://회사.atlassian.net`)·이메일·방금 만든 토큰을 붙여 넣어요.
3. `연결`을 누르면 앱이 지라에 한 번 물어봐서 확인해요. 성공하면 `○○님으로 연결됐어요`라고 표시 이름만 알려 줘요(토큰·이메일은 화면 어디에도 다시 나오지 않아요).

**앱이 지라와 무엇을 주고받나요** — 지라에는 아무것도 몰래 쓰지 않아요. 앱이 하는 일은 이 넷뿐이에요.

- **담당 티켓 읽기**: 프로젝트 목록·지라 띠 카드·하위 티켓이 여기서 와요(제 담당 티켓과 연결해 둔 티켓만 읽어요).
- **상태·배포 버전·기한 바꾸기**: 프로젝트 화면에서 직접 바꿀 수 있지만, 바꾸기 전에 **전 → 후를 보여 주는 확인 줄**을 한 번 더 거쳐요. 실행 취소(⌘Z)는 안 돼요 — 확인 줄이 그 안전장치예요.
- **에픽 만들기**: 새 프로젝트 화면에서 이름과 직군을 고르면 에픽과 직군별 하위 티켓을 만들어요. 이것도 만들기 전에 목록을 보여 주고 한 번 더 물어봐요.
- **내 댓글 알림**: 오늘 탭 맨 위 `반응 필요`가 제가 담당·보고·지켜보는 티켓 중 제 마지막 댓글 뒤에 남이 단 댓글을 모아 보여 줘요.

## 슬랙 수집

팀 슬랙 앱 하나를 워크스페이스에 설치해 두고, 쓰는 사람마다 **본인 토큰**을 받아서 써요(모두가 같은 토큰을 쓰지 않아요).

`설정 > 연동 > 슬랙 수집`에서 `연결하기`를 누르면 세 단계가 그 자리에 펼쳐져요. **링크 눌러 토큰 복사 → 붙여 넣기 → 연결**, 이게 전부예요.

1. **① 토큰 받기** — `토큰 받는 곳 열기 ↗`를 누르면 팀 슬랙 앱 페이지가 새 탭으로 열려요. `Install to Workspace`(이미 설치했으면 `Reinstall`)를 누르고 나온 `User OAuth Token`을 복사해요.
   (캡처 예정 — ![토큰 복사](img/slack-1.png))
   그 페이지가 안 열리거나 권한이 없다고 나오면, 이 앱의 `Collaborator`로 아직 추가되지 않은 거예요 — 워크스페이스를 만든 사람에게 요청해 주세요.
2. **② 토큰 붙여 넣기** — 복사한 토큰을 그 칸에 붙여 넣어요(●●●로 가려지고, 저장한 뒤에는 화면에 다시 나오지 않아요).
3. **③ 채널** — 슬랙에서 **나만 있는 비공개 채널**을 하나 만들고(이름은 아무거나, 예: `#my-todo`) 채널 이름을 우클릭 → `링크 복사` → 그 링크를 칸에 붙여 넣어요.
   - 채널을 만들기 번거로우면 아래 `앱이 대신 만들어 줄 수도 있어요 → 만들어 주기`를 눌러요. 이름만 적으면(기본 `my-todo`) 앱이 비공개 채널을 만들어 줘요. 팀 슬랙 앱에 채널 만들기 권한이 없으면 `이 슬랙 앱에는 채널 만들기 권한이 없어요 — 슬랙에서 직접 만들고 링크를 붙여 주세요`라고 알려 주니, 그때는 위의 링크 붙여 넣기로 하면 돼요.
4. `연결`을 누르면 앱이 그 채널을 읽을 수 있는지 확인하고 `#이름 · 비공개 · 잘 읽혀요`라고 알려 줘요.

**메시지를 채널에 공유(포워드)하거나 직접 적으면, 그게 곧 "이건 할 일이다"라는 표시예요.** 채널을 읽어 할 일로 옮기는 일은 지금은 Claude Code가 자동화로 돌며 해요(스레드까지 읽어 맥락을 파악하고 문구를 다듬어요). Claude Code 없이 도는 기본 수집(메시지 1개 = 할 일 1개)은 준비 중이에요 — 그때까지 Claude Code가 없으면 채널을 연결해도 할 일이 들어오지 않아요.

채널은 넷까지 쓸 수 있어요 — `③ 채널`의 첫 칸(할 일)만 필수고, 나머지 셋(맞춰야 할 것 · 언젠가 할 것 · 기다리는 것)은 `더 연결(선택)`을 펼쳐서 같은 두 갈래(링크 붙여 넣기 / 만들어 주기)로 넣으면 돼요.

**피그마·기타 알림**: 앱이 피그마를 직접 읽어 오지는 않지만, 피그마의 슬랙 알림(댓글·멘션 등)을 이 채널에 공유하면 슬랙 수집을 통해 그대로 할 일로 들어와요 — 사실상 슬랙을 거쳐 들어오는 셈이에요. 필요한 것은 위 슬랙 수집(지금은 Claude Code 포함)뿐이에요. (오늘 탭의 `반응 필요`가 보여 주는 지라 댓글과는 다른 길이에요 — 그건 앱이 지라를 직접 읽어요.)

**토큰은 채팅·메일로 보내지 말고 앱의 그 칸에만 붙여 넣어 주세요.**

## 캘린더 · 회의록(티로)

둘 다 Claude Code가 있어야 해요.

1. Claude Code 대화에서 `/mcp`로 구글 캘린더(또는 티로)를 연결해요.
2. `설정 > 연동`에서 캘린더는 토글만 켜면 되고, 회의록은 `티로`를 골라요.

**Claude Code가 없거나 쓰고 싶지 않으면**: 회의록은 `직접 옮겨서`가 기본 대안이에요 — 회의가 끝나면 회의 탭의 정리 화면에 내용을 직접 붙여 넣으면 돼요. 캘린더 연결이 없어도 프로젝트는 직접 만든 이름으로 쓸 수 있어요.

## 다른 앱을 쓰면

앱 코드를 고칠 필요는 없어요. 아래 모양으로 파일을 채우거나 API를 부르면, 슬랙·구글 캘린더·티로가 아닌 다른 도구를 써도 그대로 동작해요.

**스냅샷 파일 둘(통째로 덮어써도 돼요)**

- `tracker/calendar_today.md` — 오늘 탭의 `오늘 미팅` 카드가 읽어요.
  ```markdown
  # 오늘 캘린더 일정

  마지막 갱신: YYYY-MM-DD

  - 14:40-15:00 | 과금 유저 우대 논의
  - 15:00-16:00 | PMO 정기 회의
  ```
- `tracker/jira_issues.md` — 프로젝트를 고르는 목록이 읽는 대비책 파일이에요(앱이 지라를 직접 읽지 못할 때만 쓰여요).
  ```markdown
  # 지라 이슈 (내 담당, 진행중/백로그)

  마지막 갱신: YYYY-MM-DD

  - IO-45438 | 에픽 | 진행 중 | 보드 AI
  - IO-36600 | 에픽 | Backlog | 게시판 모아보기 기능 추가
  ```

**회의 초안 파일(끝에 추가만 해요)**

- `tracker/meeting_drafts.json` — 회의 정리 화면의 "AI가 분류한 것" 초안이에요. 형식은 `tracker/inbox-app/README.md`와 `.claude/skills/tiro-sync.md`를 참고해요(사람이 검수해서 `담기`를 눌러야 실제 목록에 들어가요).

**할 일·확인 대기·결정·아이디어는 파일을 직접 쓰지 않아요.** 대신 다음 명령 한 줄로 등록해요(서버가 켜져 있어야 해요) — 앱과 같은 검증·저장 규칙을 타는 유일한 길이에요.

```sh
node tracker/inbox-app/import-record.js item '{"type":"task","description":"정리한 한 줄","permalink":"https://원본 링크"}'
```

`type`은 `task`(할 일)·`check`(확인 대기)·`decision`(결정)·`idea`(아이디어) 중 하나, `permalink`는 그 도구에서 만든 `https://` 원문 링크예요(같은 링크로 다시 보내면 중복으로 걸러져요). `priority`·`jira`·`group`·`who`·`project`·`due`는 선택이에요.

**이 모양으로 넣으면 어떤 앱이든 돼요.** 새 도구를 붙이는 스킬(수집 지시서)이 필요하면 `설정 > 연동 > 회의록 > 다른 것`의 `요청하기`(클립보드에 복사돼요)나 슬랙 DM으로 요청해 주세요.
