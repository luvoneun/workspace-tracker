# 배포 전 실제 환경 점검

테스트와 확인용 서버(`browser-fixture.js`)는 가짜 데이터·가짜 명령으로 돈다. 아래는 **실제 맥에서만 드러나는 것**이라 배포(`release.sh`) 전에 한 번 직접 확인한다. 가장 좋은 곳은 맥의 **새 사용자 계정**(시스템 설정 › 사용자 및 그룹) — 동료의 첫 설치와 같은 조건이다.

## 새로 설치
- [ ] 팀 설치 파일(`bash make-team-installer.sh`)을 만들고, 새 계정에서 zip을 풀어 `설치.command` 우클릭 → 열기. "확인되지 않은 개발자" 경고 뒤 설치가 끝까지 도는지
- [ ] 끝에 크롬에서 앱 주소가 저절로 열리는지(크롬이 없는 계정이면 기본 브라우저 + 크롬 설치 권유 한 줄), `~/Applications`에 새 앱이 생기지 않았는지, python3 없이도 끝까지 도는지
- [ ] 오늘 탭에 사용설명서 카드, 설정을 열면 연동 탭이 먼저인지

## 연동 (실제 계정)
- [ ] 슬랙: 토큰 받는 곳 열기 → 토큰 → 채널 만들기(기본 이름이 `<슬랙 이름>-todo` 모양) → 연결. 5분 안에 전달한 메시지가 새로 들어온 것에 뜨는지(9–19시)
- [ ] 슬랙 `⋯ › 새로 받기`가 1~2분 뒤 반영되는지, 채널 고르기에서 빼기·다시 켜기
- [ ] 지라: 토큰 → 이메일 → ○○님으로 연결, 프로젝트 탭에 내 티켓
- [ ] 캘린더 비밀 주소: 오늘 일정 수가 맞는지(반복 일정·시간대 포함)
- [ ] 연동을 켜고 저장한 뒤 `업데이트.command` 없이 자동 등록되는지(`launchctl list | grep workspace.app`)

## 업데이트·되돌리기
- [ ] 한 버전 전 설치본에서 `업데이트.command` → 새 버전, 데이터 그대로
- [ ] 설정 › 앱 `업데이트 받기` 진행 목록 → 다시 켜는 중 → 완료·새로고침
- [ ] 자동 업데이트: 동료 맥(한 버전 전 설치본)에서 앱을 10분 쉬게 두면 1시간 안에 새 버전이 알아서 깔리고, 다시 열면 오늘 탭에 그 버전의 소식 카드가 서는지(`local/auto-update.json`에 `triedOn` 기록)
- [ ] 회사(playio) 폴더 안 설치본이 `~/workspace`로 옮겨지는지(`~/workspace`가 이미 있으면 멈춤)

## 꾸미기·백업
- [ ] 꾸미기 `앱 아이콘`·`앱 이름`을 바꾸면 저장 뒤 `✓ 바뀌었어요` 아래 `크롬 앱에는: …` 한 줄만 보이는지
- [ ] 크롬 앱: 사용설명서 `설치하기` → 새 창 · Dock·⌘Tab에 따로 아이콘. 아이콘을 바꾸면 `about://restart` → 앱 오른쪽 위 `앱 업데이트 있음` → ⌘Q 뒤 다시 열 때 Dock까지 바뀌는지
- [ ] 다음 날 `~/workspace-data-backup/daily/`에 날짜 폴더가 생기는지, 앱 탭 백업 줄

## 체크인·슬랙 원문 모드
- [ ] 체크인: 동료 맥(갈래 stable)에서 3일째 창이 뜨고, 보낸 답이 구글 폼 응답 탭에 한 줄로 쌓이는지(선택지 글자·자동 칸). 내 맥(main 갈래)에서는 안 뜨는지
- [ ] 사용 횟수: 동료 맥에서 업데이트 뒤 처음 연 날 폼 응답 탭에 회차 `설치` 줄이 한 번 쌓이는지, 사용설명서 맨 아래 `… 보내요 · 끄기` 줄과 설정 › 앱 `내 사용 기록` 표가 보이는지. `끄기` 뒤에는 아무 줄도 더 쌓이지 않는지
- [ ] 슬랙 원문 모드: Claude 로그인이 없는 계정에서 설정 › 연동 › 슬랙을 `원문 그대로`로 두고, 전달한 메시지가 첫 줄 그대로 들어오는지(할 일·확인 대기·결정·아이디어 채널 각각)

## 다른 기기
- [ ] Tailscale 주소로 접속 → 이름 `workspace` + 접속 암호로 열리는지(암호는 설정 › 도움말에서 복사, 대화창에 붙이지 않는다)

점검에서 나온 문제는 배포를 멈추고 고친 뒤 다시 이 목록을 돈다. 목록에 없는 새 기능이 생기면 여기에 한 줄 더한다.
