# 지도: 캘린더
> 이 주제 기능을 고치면 이 문서도 함께 고친다. 마지막 확인: 2026-09-29 · 커밋 67d41e1

## 한 줄 요약
오늘 일정(미팅)을 가져와 오늘 탭의 "오늘 미팅" 카드·회의 기록·티로 회의 매칭에 쓴다. 가져오는 길은 넷이다: 맥 캘린더(추천, `calendar.source: "mac"`) · Claude(`calendar-sync`, source가 mac·ical이 아닐 때의 예전 방식) · 비밀 주소(`ical`, 앱 서버가 메모리로 직접 읽음) · 끔(`integrations.calendar: false`).

## 고칠 때 주의
- **갈래 판단이 여러 곳에 따로 있다.** `calendar.source`·`integrations.calendar`를 읽는 곳: server.js(`CALENDAR_ICAL`·`CALENDAR_MAC` — 서버가 뜰 때 한 번), integrations.js:calendarSourceOf, calendar-mac.js:main, run-task.sh(`calendar_ical`·`calendar_mac`), setup.sh(`calendarSource`), selfcheck.js, settings-ui.js. 새 갈래·값을 더하면 전부 같이 본다. registrationKey에 갈래가 들어 있어야 저장 시 등록이 다시 돈다.
- **문구 3벌 동기화.** 맥 실패 이유는 calendar-mac.js:WORDS(로그·`NEEDS_PERSON_RE` 정규식의 재료) ↔ settings-ui.js:SETTINGS_MAC_WORDS ↔ selfcheck.js:macCalendarWhy가 `⚠️ 이유 — 고치는 법` 모양에 기대어 자른다. WORDS의 앞부분(`—` 앞)을 바꾸면 NEEDS_PERSON_RE가 자동으로 따라가지만 화면 쪽 문구는 손으로 맞춰야 한다. ` — ` 구분자를 없애면 점검 줄이 이유를 못 뽑는다.
- **`calendar_today.md` 모양은 계약이다.** `마지막 갱신: YYYY-MM-DD`와 `- HH:MM-HH:MM | 제목[ | 링크][ | id:…]`를 server.js:CALENDAR_ITEM_RE가 읽고, 맥 스냅샷(snapshotText)·Claude 스킬·티로가 같은 모양을 쓴다. 파일 감시(watchFile)와 회의 id(`externalId`)에 기대므로 내용이 같으면 다시 쓰지 않는 규칙(calendar-mac.js:main)을 지킨다.
- **서버는 프로세스를 띄우지 않는다.** 맥 갈래의 읽기는 launchd → node → osascript뿐이다. 서버 안에서 osascript를 부르게 바꾸면 안 된다(그래서 서버 메모리 보관함 방식을 못 씀). 프로세스 끝내기는 직접 띄운 자식에게만(AGENTS.md).
- **`mac-calendar-now`는 갈래와 무관하게 늘 등록**된다(연결 전 `허용하고 확인`용). setup.sh의 remove_agent 대상에 넣지 않는다. 요청 표시 파일의 `mode:check`는 스냅샷을 쓰지 않는 것이 규칙이다.
- **문서 어긋남 주의.** README·DECISIONS·calendar-mac.js/mac-calendar.sh 주석은 "매일 8–20시 30분마다"라 쓰지만 setup.sh:mac_calendar_intervals의 실제 등록은 8:00~19:30(20시 회차 없음). 고칠 때 한쪽으로 맞춘다.
- **스크립트 복사본.** automation/의 스크립트를 고치면 `~/.local/share/workspace-automation/` 복사본도 갱신(setup.sh·update.sh가 복사). 복사본은 calendar-mac.js를 저장소 경로(`WORKSPACE_DIR`)에서 실행하므로 앱 코드는 바로 반영되지만 `mac-calendar.sh` 자체는 복사본이다.
- **한 곳에서만 세는 멈춤 기준.** 톱니바퀴 빨간 점·연동 탭 `멈췄어요`·점검 ✗은 `failStuck`/`fetchStateAutomation`의 한 기준을 함께 쓴다(DECISIONS 연동 상태 줄). 화면에서 따로 판단하지 않는다.
- **비밀 주소는 토큰과 같은 급**: 응답·로그·화면·`calendarLive.history()`에 주소를 싣지 않는다(DECISIONS 2026-09-24 캘린더 비밀 주소 줄).
- **공개 저장소**: 문구·테스트 예시에 실제 이메일·회사명을 넣지 않는다.
- 관련 DECISIONS: 2026-09-24 캘린더 비밀 주소 직접 읽기(122행 부근), 2026-09-24 `지금 가져오기`의 갈래별 동작(126행), 2026-09-24 저장 시 등록 자동화(133행), 2026-09-29 맥 캘린더 갈래 WP-V(142행), 2026-09-22 회의 탭 기본 목록(76행), 2026-09-20 슬랙 수집의 캘린더·지라 실행 권한 언급(28행). 행 번호는 이 커밋 기준이라 바뀔 수 있다.
