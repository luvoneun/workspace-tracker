## 뜨는 것 — 떠 있는 요소를 새로 만들 때
- 붙이기는 `uiFloatOpen(el)`(창 안이면 `{ parent }`), 자리는 `uiFloatPlace(el, 누른 것, { align, gap, pad })`, 닫기는 `uiFloatClose(el)`. 요소에 `animation`을 따로 적지 않는다 — 값은 `ui.css` `.d-float` 한 곳이고, 다르게 해야 하면 그 요소 규칙에서 변수(`--float-in`·`--float-from`·`--float-over`·`--float-to`)만 바꾼다(상세 카드가 그렇게 넘침을 줄인다).
- 닫힘은 **죽은 복사본**이 재생한다(`uiFloatGhost`). 진짜 요소는 닫는 순간 떨어지므로 Esc 차례·초점 복귀·다시 그리기는 닫힘 재생을 기다리지 않는다. 자리가 남는 요소(`hidden`으로 켜고 끄는 시트·가림막)는 숨기기 직전에 `uiFloatGhost(el)`만 부른다.
- 키보드로 연 것은 `uiFloatOpen`이 알아서 나타남만으로 바꾼다(`uiActByKey`). 늘 줄여야 하는 것(팔레트)은 `{ flat: true }`.
- 움직임 줄이기는 따로 등록하지 않는다 — `.d-float`가 전역 규칙에 한 번 등록돼 있다.
- **자리가 남는 것**(알림·창·막대 — 한 번 붙여 두고 `hidden`·`<dialog>`로 켜고 끈다)은 부품 클래스 `.d-stay` 하나만 건다. 여닫는 화면 코드는 그대로다(`showNotice`·`settingsClose`·`wrapClose` 정의, 창의 `showModal`·`close`). 등장은 `@starting-style`, 닫힘은 표시가 꺼질 때 `transition-behavior: allow-discrete` 전환이 재생한다(크롬 154에서 확인 — 모르는 환경은 지금처럼 바로 뜨고 바로 닫힌다). 그래서 떠 있는 알림에 새 글이 와도 다시 튀지 않고, 닫히는 중에 다시 열면 그 자리에서 되돌아오며(깜박임 없음), `hidden`·`open`은 닫는 순간 바뀌어 초점 복귀·Esc 차례가 기다리지 않는다. 닫히는 동안은 `interactivity: inert`로 눌리지 않는다.
- 닫을 때 **내용을 비우는** 것(선택 막대·모으기 막대)은 비우기 직전에 `uiFloatGhost(bar)`를 부른다 — 복사본(`.d-stay.is-out`)이 닫힘을 재생한다. 창은 복사본이 맨 위 층(top layer)에 오르지 않아 이 길을 못 쓰므로, 창을 닫을 때는 내용을 비우지 않는다(오늘 정리 창은 다시 열 때 새로 그리고, 체크인 창은 닫힘이 끝난 뒤 떼어 낸다).
- 새 창을 만들면 `class="d-modal d-stay"`로 시작한다 — 시험이 `<dialog>`마다 `.d-stay`를 보고, `showModal` 개수를 파일마다 못 박는다.

### 사람이 볼 것 (합치기 전 한 번)
닫힘 복사본 수동 점검: ⋯ 메뉴 · 분류 판 · 회의 줄 종류 목록 · 상세 카드(좁은 폭이면 아래 시트) · 검색(⌘K) 다섯 가지를 한 번씩 여닫는다 — ① 안을 스크롤해 둔 채 닫아도 닫히는 동안 내용이 맨 위로 튀지 않는지 ② 항목을 눌러 닫으면 그 항목만 누름 색을 든 채 사라지고, Esc·바깥 클릭으로 닫으면 아무 항목도 색이 바뀌지 않는지 ③ 닫자마자 다시 열어도 새것이 뜨고 옛것은 눌리지 않는지 ④ 안쪽 목록을 스크롤해 둔 메뉴를 연 채 회의 줄의 `할 일 ⌄`을 누르면 종류 목록이 뜬 채로 있는지.
자리가 남는 것 수동 점검(B2): 알림이 떠 있을 때 할 일을 연달아 체크해도 알림이 다시 튀지 않는지 · 설정 창(톱니바퀴)을 열고 Esc로 닫자마자 다시 열어도 깜박이지 않는지, 닫으면 초점이 톱니바퀴로 바로 돌아오는지 · 오늘 정리 창이 무겁게 느껴지지 않는지 · 할 일 `여러 개 선택`을 켰다 끌 때 막대가 내려가는지 — 라이트·다크 한 번씩.

## 줄 — 목록을 새로 만들 때
- 줄을 통째로 갈아 끼우는 그리기는 `uiRowsMove(목록, () => 그리기())`로 감싼다(`app.js`). 줄마다 열쇠 하나를 단다 — 업무 줄 `data-task-id`, 레일 줄 `data-rail-id`(`uiRailRow`가 단다), 그 밖은 `data-move-id`(목록 안에서 겹치지 않게 앞머리를 붙인다: 미팅 `mt:`, 배포 `deploy:`, 반응 필요 `at:`, 그룹 제목 `grp:`). 열쇠가 없는 줄(빈 상태 글·`외 N개 보기`)은 움직이지 않는다.
- 위아래로 이어진 목록(한쪽이 줄면 다른 쪽 줄이 밀리는 것)은 `app.js` `UI_GLIDE_LISTS`의 한 무리에 넣는다 — 같은 틱의 그리기를 함께 재고, 상한(보이는 40줄·전체 150줄)도 무리마다 센다. 무리 안에서는 다른 목록으로 옮겨 간 줄도 잇는다(새로 들어온 것 → 오늘, 결정 → 반영 완료). 무리에 없는 목록은 제 목록만 잰다.
- 사라진 줄은 도우미가 옛 자리에 그림자 한 장(`.d-glide-ghost` — 열쇠·id 없고 누를 수 없음)을 붙여 120ms 흐리고 떼어 낸다. 체크해서 접힌 제목으로 들어가는 줄은 부르는 쪽이 `uiGlideDoneMark(id, 들어갈 제목의 열쇠·id, 긋기를 기다리나)`를 남긴다 — 업무 완료 `grp:완료`(긋기 200ms 뒤 무리 전체가 함께 움직인다), 결정 반영 `decisionArchiveToggle`.
- 숨어 있던 목록(처음 연 탭)을 그리는 것은 처음 그리기라 줄이 떠오르지 않고(목록 상자가 없었는지 본다), 8px 이하의 가로 어긋남(창 스크롤바)은 잇지 않는다. 체크 표시는 2초만 믿고, 다시 그려진 줄이 완료 줄일 때만 긋기를 잇는다. 그림자는 목록마다 한꺼번에 붙이고 자리 기준을 한 번만 잰다.
- 빠른 추가 칸(Enter로 적고 칸에 초점이 남는 것)은 keydown에서 `uiGlideAddMark(input, event)`를 부른다 — 그 저장 뒤 다시 그리기에서 새 줄만 140ms 나타나고 다른 줄은 그대로 선다.
- 입력 보호가 먼저다: 글자 칸·한글 조합·칸 안 글 고치기 중이면 도우미가 아무것도 걸지 않고, `uiRenderOrHold`로 미뤘다 푸는 그리기는 `uiGlideUnlessLate`로 감싸 움직이지 않는다. 새 목록을 등록하면 `client.test.js`의 C1 목록 표(`C1_LISTS`)처럼 입력 보류 시험을 같이 넣는다.

### 사람이 볼 것 (C1, 합치기 전 한 번)
오늘 할 일을 하나 체크한다 — 체크가 톡 → 줄이 그어지고 → (0.2초쯤 멈췄다가) 줄이 `완료 N` 쪽으로 미끄러지며 사라지고 아래 줄이 올라오는 박자가 굼뜨지 않은지. 연달아 서너 개를 빠르게 체크해도 정신없지 않은지. 확인 대기를 체크하면 그 줄이 맨 위 `다음은?` 자리로 올라가는지, ⋯ `급한 순`으로 바꾸면 줄이 미끄러지는지. 아이디어·결정 탭에서 결정을 체크하면 줄이 아래 `반영 완료`로 빠지는지, `결정 추가`에 적고 Enter를 치면 새 줄만 살짝 나타나고 다른 줄은 그대로인지 — 라이트·다크 한 번씩.

## 누름 — 버튼을 새로 만들 때
- 모든 `button`과 체크박스는 아무것도 적지 않아도 눌린다(.97, 100ms, 넘침 없음)와 색 전환(170ms)을 갖는다.
- 버튼 부품에 `transition`을 따로 적으면 공용 줄을 덮는다 — 그 선언 끝에 `scale var(--t-press) var(--ease)`를 함께 적는다. 시험이 CSS 네 파일의 `transition` 선언을 전부 훑는다 — 누름 전환을 적었거나, 뺀 것이거나, 버튼이 아닌 것(시험 안 `MOTION_NOT_PRESSED`에 이유와 함께)이어야 통과한다.
- 누름은 `transform`이 아니라 `scale` 속성이다 — 아이콘 회전·체크 커짐 같은 `transform`과 섞이지 않는다.
- 움직임 줄이기에서는 크기 변화가 꺼지고 색만 바뀐다(색도 전역 규칙에 따라 바로 바뀐다).

### 누름에서 뺀 것 (의도적으로 줄어들지 않음 — 색으로만 답한다)
`ui.css`의 "누름에서 뺀 것" 선택자 목록 하나에 모여 있다. 넓거나 글자뿐인 버튼을 새로 만들면 거기에 더한다.

**누름 = 색 한 단계.** 뺀 것 가운데 배경이 있는 것은 바로 아래 규칙(`ui.css` `.d-mitem:active:not(:disabled)` 묶음)에도 넣는다 — 누르는 동안 배경이 `--press`(가리킴보다 한 단계 진하게, 100ms)가 된다. 글자뿐인 것·따뜻한 카드 위의 안내 줄·꺼진 것은 색도 없다(시험 안 `MOTION_PRESS_NO_COLOR`에 이유와 함께). 뺀 목록에 넣고 둘 중 어디에도 안 넣으면 시험이 실패한다.

| 갈래 | 선택자 | 이유 |
|---|---|---|
| 글자 탭·글자 링크·글자 제목 | `.d-tab` `.d-srch` `.d-link` `.wf-link` `.rp-rename` `.d-title` · 줄 제목 `.ti`(미팅·확인 대기·회의·프로젝트·기록·주간요약 줄) | 글자가 줄어들면 흔들려 보인다. 누름 색은 배경 판이 있는 `.d-srch`·`.rp-rename`만 |
| 메뉴·고르개 항목 | `.d-mitem` `.d-mpickbtn` `.jira-pick` `.d-gpopt` `.d-pres` `.d-dpick` `.d-fields .badge.is-plain` `.rp-pick` `.rp-ev .ev` | 누름 = 색 한 단계(`--press`). 화살표로 연달아 옮겨 다닌다. 앞의 다섯은 색 전환도 없다(세기 0) |
| 줄 전체가 버튼인 것 | `.d-grp.tog` `.d-guide` `.d-prow` `.d-plink` `.d-mtrow` `.d-jfold` `.d-jlink .pk` `.rp-wk` `.rp-fl` `.rp-gp` `.d-uwmore` | 누름 = 색 한 단계(`--press`, `.d-guide`만 빼고). 줄이 줄면 목록이 흔들린다(폭 200px이면 6px이 움직인다) |
| 꺼진 버튼·잠긴 체크 | `button:disabled` `.d-cb:disabled` `.d-wcb:disabled` | 눌리지 않는 것은 답하지 않는다 |
| 입력칸·줄 전체가 label인 체크 줄(`.d-ich`) | (버튼이 아니라 규칙이 걸리지 않는다) | 글자 입력 / 줄 전체 |

### CSS만으로는 안 되는 곳
CSS에 전환이 적혀 있어도, 누르면 그 요소를 **새로 만들어 갈아 끼우는** 곳에서는 전환이 재생되지 않는다(코드로 본 추정 — 눈으로 확인하지 못했다). 그리기 앞뒤를 잇는 도우미가 필요하다.

| 곳 | 맡은 묶음 |
|---|---|
| 그룹 접기 꺾쇠(오늘·회의·프로젝트·오늘 정리·주간요약 문장·지라 하위 티켓) | D |
| 세그먼트의 고른 버튼 색(오늘 보기·아이디어·결정·회의·프로젝트·새 프로젝트) | E — 손잡이 |
| 켜고 끄는 칩의 켜진 색(회의 필터, `나중에 할 일에도 추가`, 메뉴 안 값 칩), 설정의 체크 줄 켜짐 배경 | E |
| 상세가 열린 줄·여러 개 고른 줄의 배경(줄이 다시 그려질 때) | C |
| 오늘 정리 창의 요약 칩 초록 전환 | D |
| ~~레일 체크의 커졌다 돌아오기(체크하면 줄이 바로 빠진다)~~ → 풀림: 체크한 줄이 맨 위 `다음은?` 자리로 다시 그려지며 미끄러져 체크가 보인다(C1) | — |

## 안 움직이는 곳과 이유
전수 목록에서 상태가 `의도적으로 안 움직임`인 줄이다. 갈래는 여덟 가지다.

| 갈래 | 이유 |
|---|---|
| 글자 입력의 시작·도중(그 자리 입력칸, 문구 칸 높이, 찾기로 거르기) | 글자를 치려고 누른 것 — 1ms도 늦추지 않는다. 한글 조합 보호와도 얽힌다 |
| 자동 갱신으로 바뀌는 것(지라 띠, 상태 점, 미팅 지금 표시, 새 기록 칩, 날짜 칩) | 내가 한 일이 아닌 변화가 움직이면 시선을 뺏는다 |
| 키보드로 연달아 하는 것(메뉴 항목·팔레트 결과의 가리킴) | 연타 중에 움직이면 느려진다 |
| 기다린 내용이 나타나는 순간, 오류·빈 상태 글 | 기다린 것은 바로 보여야 한다 — 기다리는 **동안**만 표시한다 |
| 경고(저장 멈춤 배너, 경고 점) | 경고는 연출 없이 바로 |
| 높이·폭(설정 창의 탭마다 달라지는 높이, 창 폭에 따른 재배치) | 높이·폭·여백은 움직이지 않는다는 원칙 |
| 결과 미리보기(주간요약의 슬랙 미리보기) | 고칠 때마다 바뀌는 화면 — 움직이면 읽기 어렵다 |
| 글자 탭·글자 링크의 누름 | 글자가 줄어들면 흔들려 보인다 — 색으로만 |
